# 용어집

문서와 코드에서 같은 개념을 같은 이름으로 부르기 위한 목록입니다. 코드 이름은 [[01-model]] 설계에서 확정되면 갱신합니다. 화면의 글자는 영어가 기본이므로([[01-requirements#^nfr-i18n]]), "영어" 칸이 화면에 쓸 낱말의 후보입니다.

> [!note] 낱말을 고를 때
> - **고르기**: 사용자가 블록을 집는 일은 "고르기"라고 씁니다. "선택"은 If 블록의 옛 이름(선택 블록)과 겹치므로 쓰지 않습니다. 예전 문서에 남은 "선택 영역"은 "고른 영역"과 같은 뜻입니다.
> - **머리**: 다이어그램 맨 위와 If · Case · 반복 블록의 조건 칸은 모두 "머리"라고 씁니다. "헤더"는 쓰지 않습니다.

## 문서와 다이어그램

| 용어 | 영어 | 코드 이름(안) | 뜻 |
| --- | --- | --- | --- |
| 문서 | document | `Document` | 파일 하나. 다이어그램 여러 개와 문서 설정을 담는다 → [[01-requirements#^edit-multi-diagram]] |
| 다이어그램 | diagram | `Diagram` | NS 차트 하나. 머리(없을 수도 있음)와 본문으로 이루어진다 |
| NS 차트 | Nassi-Shneiderman diagram | — | 구조적 프로그래밍을 상자 안의 상자로 나타낸 도표. 이 제품이 그리는 것 |
| 머리 | head | `Head`(안) | 다이어그램 맨 위의 칸. 없거나, Event 머리이거나, Method 머리다 |
| Event | event | `kind: event`(안) | 문서 밖에서 시작되는 다이어그램(인터럽트, 타이머, 받은 메시지). 모자 모양 머리를 단다. 호출 블록으로 부를 수 없다 → [[0021-event-and-method\|ADR-0021]] |
| Method | method | `kind: method`(안) | 호출 블록이 부르는 다이어그램. 폭 전체에 걸친 낮은 아치 머리를 단다. 머리의 첫 여는 괄호 앞까지가 이름이고, 괄호 안이 받는 것이다 → [[0022-call-name-follows-head\|ADR-0022]] |
| 본문 | body | `body` | 다이어그램 머리 아래의 블록 목록. 반복 블록 안에서 반복되는 블록 목록도 본문이라고 한다 |
| 문서 설정 | document settings | `settings`(안) | 문서마다 정해 파일에 저장하는 것: 블록 글자의 종류, 결과 기호 등 |

## 블록

| 용어                 | 영어                                       | 코드 이름(안)          | 뜻                                                                                                                              |
| ------------------ | ---------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 블록                 | block                                    | `Block`           | 다이어그램을 이루는 사각형 하나. 트리의 노드                                                                                                      |
| 시퀀스                | sequence                                 | `Sequence`        | 위에서 아래로 차례로 실행되는 블록 목록                                                                                                         |
| 처리 블록              | process                                  | `ProcessBlock`    | 한 단계의 명령                                                                                                                       |
| 제어 블록              | control block                            | —                 | 다른 블록을 안에 품는 블록 (If, Case, 반복)                                                                                                 |
| If 블록 (선택 블록)      | if-then-else                             | `IfBlock`         | 조건에 따라 참 · 거짓 갈래 가운데 하나를 실행                                                                                                    |
| Case 블록 (다중 선택 블록) | switch/case                              | `CaseBlock`       | 값에 따라 여러 갈래 가운데 하나를 실행. 맨 끝은 늘 default 갈래                                                                                      |
| 전위 판정 반복           | while (pre-test loop)                    | `WhileBlock`      | 조건을 먼저 검사하는 반복                                                                                                                 |
| 후위 판정 반복           | do-while / repeat-until (post-test loop) | `DoWhileBlock`    | 본문을 먼저 실행하고 조건을 검사하는 반복                                                                                                        |
| 횟수 반복              | for                                      | `ForBlock`        | 정해진 횟수만큼 반복                                                                                                                    |
| 호출 블록              | call                                     | `CallBlock`       | 같은 문서의 Method를 부르는 블록. 양옆 세로 이중선으로 그린다(NS 차트 표준의 서브루틴 호출 표기). `결과 ← 이름(인자)` 꼴로 보인다 → [[0022-call-name-follows-head\|ADR-0022]] |
| 인자 · 결과            | arguments · result                       | `args` · `result` | 호출 블록마다 적는 글자. 이름은 적지 않고 Method의 머리를 따른다                                                                                       |
| 결과 기호              | result symbol                            | —                 | 결과를 받는 기호 `←` 또는 `=`. 문서 설정이고 보기 상태로 다룬다(실행 취소의 대상이 아님)                                                                        |
| 갈래                 | branch                                   | `Branch`          | If · Case 안의 각 경로. 시퀀스 하나를 가진다. Case의 갈래에는 갈래 이름이 있다                                                                           |
| 조건                 | condition                                | `condition`       | If · Case · 반복 블록의 머리에 적는 판정 글자                                                                                                |
| 블록 글자              | block text                               | `text`            | 블록에 적는 글자. 문서마다 종류(문장, C, Java …)를 고른다 → [[01-requirements#^lay-text-kind]]                                                    |

## 편집

| 용어 | 영어 | 뜻 |
| --- | --- | --- |
| 고르기 | select | 블록을 집는 일. 고른 것은 늘 같은 부모 아래 이어진 블록들이다 → [[0008-contiguous-selection\|ADR-0008]] |
| 고른 영역 (선택 영역) | selection range | 고른 블록들. 다른 깊이의 블록까지 고르면 둘을 함께 담는 가장 가까운 범위로 넓어진다(자동 확장) |
| 감싸기 | wrap (surround with) | 고른 블록들을 새 제어 블록 안에 넣는 편집 |
| 풀기 | unwrap | 껍데기를 없애고 안의 것을 남기는 편집. 제어 블록을 골랐으면 그 제어 블록을 벗기고, 그 안의 블록을 골랐으면 담은 가장 가까운 제어 블록을 벗기며, 호출 블록을 골랐으면 부르는 Method의 블록들로 바꾼다 → [[05-ux-decisions#Q7. 푸는 명령을 하나로 (R5)\|Q7]] |
| 편집 명령 | command | 모델을 바꾸는 단위 작업. 실행 취소의 단위와 같다 |
| 내용 · 보기 상태 | content · view state | 파일에 저장되는 것의 두 갈래. 내용(블록, 글자, 구조, 접기 영역)을 바꾸면 실행 취소의 대상이고, 보기 상태(접힘, 펴 보기, 이름 띠 보기, 결과 기호)는 대상이 아니다 → [[02-interaction-rules#6. 실행 취소]], [[0018-save-as-shown\|ADR-0018]] |

## 접기와 펴 보기

| 용어 | 영어 | 뜻 |
| --- | --- | --- |
| 접기 | fold | 안쪽을 감추고 머리나 이름만 보이게 하는 것. 제어 블록의 안쪽(If · Case는 갈래별)과 접기 영역을 접는다. 같은 명령이 펴 보인 호출 블록도 접는다 → [[02-interaction-rules#접기 · 펼치기]] |
| 접기 영역 | fold region | 같은 부모 아래 이어진 블록들의 묶음. 접으면 한 칸으로 줄고 이름이 보인다. 펴도 남아 있고, 이름과 함께 파일에 저장된다. 블록 하나로도 만든다 → [[0017-fold-name-in-model\|ADR-0017]]. 예전에는 "이름 붙은 영역", "이름 붙은 범위"라고 적었다 |
| 이름 띠 | name band | 펴진 접기 영역 맨 위에 붙는 얇은 줄. 이름이 적혀 있고 둘레의 테두리와 함께 켜고 끈다 |
| 접힌 칸 | folded region row | 접힌 접기 영역이 줄어든 한 칸. `▶`과 이름이 보인다 |
| 접힌 줄 | folded lane row | 접힌 제어 블록의 갈래 자리에 보이는 한 줄. "⋯ 블록 n개"가 보인다 |
| 펴 보기 | expand in place | 호출 블록 자리에 부르는 Method의 블록을 보기로만 보여 주는 것. 펴 보인 블록은 고칠 수 없다 → [[02-interaction-rules#호출 블록 펴 보기]] |
| 펴 보인 곳의 접기 영역 | site fold region | 펴 보인 호출 블록 자리에만 있는 접기 영역. Method의 원본에는 없다 → [[02-interaction-rules#펴 보인 곳의 접기 영역]] |
