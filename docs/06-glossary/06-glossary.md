# 용어집

문서와 코드에서 같은 개념을 같은 이름으로 부르기 위한 목록입니다. 코드 이름은 [[01-model]]의 타입과 필드 이름을 따릅니다. 화면의 텍스트는 영어가 기본이므로([[01-requirements#^r-nfr|R-NFR-04]]), "영어" 칸이 화면에 쓸 단어의 후보입니다.

> [!note] 단어를 고를 때
> - **선택**: 사용자가 블록을 집는 일은 "선택"이라고 씁니다(2026-11-01부터. 그 전의 문서는 "고르기"라고 적었습니다). If 블록의 옛 이름 "선택 블록"은 쓰지 않습니다.
> - **헤더 · 조건 칸**: 다이어그램 맨 위의 칸(Event 헤더 · Method 헤더)만 "헤더"라고 씁니다(2026-11-01부터. 그 전의 문서는 "머리"라고 적었습니다). If · Case · While · For의 윗부분과 Do-While의 아랫부분, 조건을 적는 곳은 "조건 칸"이라고 씁니다(2026-11-03부터. 2026-11-01부터 이날까지는 이것도 "헤더", 그 전에는 "머리"라고 적었습니다).
> - **붙여넣기**: 복사한 것을 넣는 일은 "붙여넣기"라고 씁니다. "붙이기"는 쓰지 않습니다.
> - **SW 용어**: 순한국어로 지어낸 말이나 영어를 직역한 말 대신 한국의 SW 엔지니어가 쓰는 말을 씁니다(2026-11-01부터: 시험 → 테스트, 판 → 버전, 갈래 → 분기, 고치기 → 편집, 넣기 → 삽입, 지우기 → 삭제, 옮기기 → 이동, 글자 → 텍스트, 임시 보관 → 로컬 백업 …). 그 전의 기록(`atelier/`)은 그때의 말 그대로입니다.

## 문서와 다이어그램

| 용어 | 영어 | 코드 이름 | 뜻 |
| --- | --- | --- | --- |
| 문서 | document | `Doc` | 파일 하나. 다이어그램 여러 개와 문서 설정을 담는다 → [[01-requirements#^r-edit\|R-EDIT-18]] |
| 다이어그램 | diagram | `Diagram` | NS 차트 하나. 헤더(없을 수도 있음)와 본문으로 이루어진다 |
| NS 차트 | Nassi-Shneiderman diagram | — | 구조적 프로그래밍을 상자 안의 상자로 나타낸 도표. 이 제품이 그리는 것 |
| 헤더 | head | `Head` | 다이어그램 맨 위의 칸. 없거나, Event 헤더이거나, Method 헤더다. 예전에는 "머리"라고 적었다 |
| Event | event | `kind: 'event'` | 문서 밖에서 시작되는 다이어그램(인터럽트, 타이머, 받은 메시지). 모자 모양 헤더를 단다. 호출 블록으로 호출할 수 없다 → [[0021-event-and-method\|ADR-0021]] |
| Method | method | `kind: 'method'` | 호출 블록이 호출하는 다이어그램. 폭 전체에 걸친 낮은 아치 헤더를 단다. 헤더의 첫 여는 괄호 앞까지가 이름이고, 괄호 안이 받는 것이다 → [[0022-call-name-follows-head\|ADR-0022]] |
| 본문 | body | `body` | 다이어그램 헤더 아래의 블록 목록. 반복 블록 안에서 반복되는 블록 목록도 본문이라고 한다 |
| 문서 설정 | document settings | `settings` | 문서마다 정해 파일에 저장하고, 바꾸면 실행 취소의 대상인 것: 블록 텍스트의 언어, 그림 문구의 언어, 테마, 헤더 모양. 결과 기호도 문서마다 하나이고 파일에 저장되지만 뷰 상태다 |
| 그림 문구의 언어 | language of drawn labels | `settings.locale` | 편집기가 그림에 적는 고정 문구(If의 "참" · "거짓", "⋯ 블록 n개", "(이름 없음)")의 언어. 문서 설정이다. 새 문서는 만든 사람의 화면 언어로 시작한다. 메뉴 · 알림은 화면 언어를 따른다 → [[0041-drawing-locale-in-document\|ADR-0041]] |

## 블록

| 용어 | 영어 | 코드 이름 | 뜻 |
| --- | --- | --- | --- |
| 블록 | block | `Block` | 다이어그램을 이루는 사각형 하나. 트리의 노드 |
| 시퀀스 · 줄 | sequence | `Seq` | 위에서 아래로 차례로 실행되는 블록 목록. 다이어그램 · 분기 · 반복 블록의 본문이 모두 줄이다 |
| 처리 블록 | process | `Process` | 한 단계의 명령 |
| 제어 블록 | control block | — | 다른 블록을 안에 품는 블록 (If, Case, 반복) |
| If 블록 | if-then-else | `If` | 조건에 따라 참 · 거짓 분기 가운데 하나를 실행 |
| Case 블록 (다중 선택 블록) | switch/case | `Case` | 값에 따라 여러 분기 가운데 하나를 실행. 편집기로 만든 Case는 맨 끝에 default 분기가 있다. 코드에서 가져온 것은 없을 수도 있다 |
| 전위 판정 반복 | while (pre-test loop) | `While` | 조건을 먼저 검사하는 반복 |
| 후위 판정 반복 | do-while / repeat-until (post-test loop) | `DoWhile` | 본문을 먼저 실행하고 조건을 검사하는 반복 |
| 횟수 반복 | for | `For` | 정해진 횟수만큼 반복 |
| 호출 블록 | call | `Call` | Method를 호출하는 블록. 같은 문서의 Method, 이름만 적은 함수, 다른 문서의 Method를 호출한다. 양옆 세로 이중선으로 그린다(NS 차트 표준의 서브루틴 호출 표기). `결과 ← 이름(인자)` 꼴로 보인다 → [[0022-call-name-follows-head\|ADR-0022]] |
| 인자 · 결과 | arguments · result | `args` · `result` | 호출 블록마다 적는 텍스트. 이름은 적지 않고 Method의 헤더를 따른다 |
| 결과 기호 | result symbol | `resultSymbol` | 결과를 받는 기호 `←` 또는 `=`. 문서마다 하나이고, 뷰 상태다(파일에 저장되지만 실행 취소의 대상이 아님) → [[ux-decisions#Q9. 실행 취소의 대상 (R7)\|Q9]] |
| 분기 | branch | `Branch` · `Arm` | If · Case 안의 각 경로. 줄 하나를 가진다. 분기마다 분기 라벨이 있다(If는 처음에 "참" · "거짓", Case는 사용자가 적음). If의 분기와 default 분기는 `Branch`, Case의 나머지 분기는 `Arm`. 예전에는 "갈래"라고 적었다(분기 라벨은 "갈래 이름") |
| 조건 칸 | condition cell | — | If · Case · While · For의 윗부분, Do-While의 아랫부분. 조건을 적는 곳이다. If · Case에서는 빗금과 분기 라벨 줄도 이 칸에 있다. 다이어그램의 헤더와는 다르다. 레이아웃 코드에서는 `head`(`headHeight`)라고 부른다. 2026-11-03까지는 "헤더"라고 적었다 |
| 조건 | condition | `text` | 제어 블록의 조건 칸에 적는 판정 텍스트. 블록 텍스트와 같은 필드다 |
| 블록 텍스트 | block text | `text` | 블록에 적는 텍스트. 문서마다 언어(일반 텍스트, C, Java …)를 선택한다 → [[01-requirements#^r-lay\|R-LAY-06]]. 예전에는 "블록 글자"라고 적었다(언어는 "종류", 일반 텍스트는 "문장") |

## 편집

| 용어 | 영어 | 뜻 |
| --- | --- | --- |
| 선택 | select | 블록을 집는 일. 선택한 것은 늘 같은 부모 아래 이어진 블록들이다 → [[0008-contiguous-selection\|ADR-0008]] |
| 선택 영역 | selection range | 선택한 블록들. 다른 깊이의 블록까지 선택하면 둘을 함께 담는 가장 가까운 범위로 넓어진다(자동 확장) |
| 감싸기 | wrap (surround with) | 선택한 블록들을 새 제어 블록 안에 넣는 편집 |
| 풀기 | unwrap | 래퍼를 없애고 안의 것을 남기는 편집. 제어 블록을 선택했으면 그 제어 블록을 벗기고, 그 안의 블록을 선택했으면 담은 가장 가까운 제어 블록을 벗기며, 호출 블록을 선택했으면 호출하는 Method의 블록들로 바꾼다 → [[ux-decisions#Q7. 푸는 명령을 하나로 (R5)\|Q7]] |
| 새 Method로 빼기 | extract into new Method | 선택한 블록들을 새 Method의 본문으로 옮기고, 그 자리에 그 Method를 호출하는 호출 블록을 남기는 편집. 풀기(호출 블록)의 반대다 → [[02-interaction-rules#새 Method로 빼기와 새 다이어그램]] |
| 붙여넣기 | paste | 복사하거나 잘라낸 블록을 선택한 것 뒤(또는 앞)에 넣는 편집 → [[02-interaction-rules#붙여넣기]] |
| 편집 완료 | finish editing | 인라인 에디터를 닫으며 적은 텍스트를 문서에 넣는 일. `Enter` · `Esc`(→ [[dr-0009-vim-keys\|DR-0009]]), 다른 곳 클릭, 편집하는 중에도 듣는 키(`Ctrl`+`S` 등)가 편집을 완료한다 → [[03-editor#3.4 텍스트 편집]]. 2026-11-03까지는 "받아들이기"라고 적었다 |
| 편집 명령 | command | 모델을 바꾸는 단위 작업. 실행 취소의 단위와 같다 |
| 내용 · 뷰 상태 | content · view state | 파일에 저장되는 것의 두 가지. 내용(블록, 텍스트, 구조, 접기 영역, 문서 설정)을 바꾸면 실행 취소의 대상이고, 뷰 상태(접힘, 펴 보기, 이름 띠 보기, 결과 기호)는 대상이 아니다. 코드 이름은 `view`다 → [[02-interaction-rules#6. 실행 취소]], [[01-model#2. 뷰 상태]], [[0018-save-as-shown\|ADR-0018]]. 예전에는 뷰 상태를 "보기 상태"라고도 적었다 |

## 접기와 펴 보기

| 용어 | 영어 | 뜻 |
| --- | --- | --- |
| 접기 | fold | 안쪽을 감추고 조건 칸이나 이름만 보이게 하는 것. 제어 블록의 안쪽(If · Case는 분기별)과 접기 영역을 접는다. 같은 명령이 펴 보인 호출 블록도 접는다 → [[02-interaction-rules#접기 · 펼치기]] |
| 접기 영역 | fold region | 같은 부모 아래 이어진 블록들의 묶음. 접으면 한 칸으로 줄고 이름이 보인다. 펴도 남아 있고, 이름과 함께 파일에 저장된다. 블록 하나로도 만든다 → [[0017-fold-name-in-model\|ADR-0017]]. 예전에는 "이름 붙은 영역", "이름 붙은 범위"라고 적었다 |
| 이름 띠 | name band | 펴진 접기 영역 맨 위에 붙는 얇은 줄. 이름이 적혀 있고 둘레의 테두리와 함께 켜고 끈다 |
| 접힌 칸 | folded region row | 접힌 접기 영역이 줄어든 한 칸. 이름이 보인다. 편집할 때는 앞에 펼침 삼각형 `▸` |
| 접힌 줄 | folded lane row | 접힌 제어 블록의 분기 자리에 보이는 한 줄. "⋯ 블록 n개"가 보인다 |
| 펴 보기 | expand in place | 호출 블록 자리에 호출하는 Method의 블록을 보기로만 보여 주는 것. 펴 보인 블록은 편집할 수 없다 → [[02-interaction-rules#호출 블록 펴 보기]] |
| 펴 보인 곳의 접기 영역 | site fold region | 펴 보인 호출 블록 자리에만 있는 접기 영역. Method의 원본에는 없다 → [[02-interaction-rules#펴 보인 곳의 접기 영역]] |

## 화면 (UI)

편집 화면의 부분과 조작의 이름입니다. 웹의 배치는 [[05-screen-layout|화면 배치]], 화면의 구조는 [[03-editor#1. 화면 구성]]에 있습니다.

| 용어 | 영어 | 뜻 |
| --- | --- | --- |
| 메뉴 바 | menu bar | 화면 맨 위의 메뉴(파일 · 편집 · 다이어그램 · 보기 · 도움말). 데스크톱은 운영체제의 메뉴 바에 둔다 → [[03-editor#5.1 메뉴 구성]] |
| 툴바 | toolbar | 메뉴 바 아래의 버튼 한 줄(파일, 되돌리기, 복사, 블록 아이콘, 감싸기, 확대) → [[05-screen-layout\|화면 배치]] |
| 블록 아이콘 | block icon | 툴바에서 블록의 모양을 줄인 버튼 여섯. 누르면 삽입하고, `Ctrl`+클릭하거나 블록 위에 끌어 놓으면 감싼다 → [[02-interaction-rules#블록 아이콘으로 삽입 · 감싸기]] |
| 컨텍스트 메뉴 | context menu | 오른쪽 클릭으로 여는 메뉴. 선택한 것에 적용되는 명령이 나온다 → [[03-editor#1. 화면 구성]] |
| 커맨드 팔레트 | command palette | 명령 이름의 일부를 쳐서 찾아 실행하는 창. Obsidian에서는 Obsidian의 명령 팔레트(Command palette)에 같은 명령을 올린다 → [[02-interaction-rules#커맨드 팔레트]] |
| 키 힌트 | key hint | 두 키 조합의 첫 키를 누르고 0.4초가 지나면 캔버스 아래에 뜨는, 이어 누를 키와 명령의 목록 → [[03-keymap]] |
| 상태 표시줄 | status bar | 화면 맨 아래 줄. 선택한 것과 알림을 보인다 → [[05-screen-layout\|화면 배치]] |
| 모달 | modal | 편집 화면 위에 띄워, 닫을 때까지 다른 조작을 막는 창(문서 설정, 환경 설정, 단축키 목록). 편집 화면 안의 창은 "대화상자"라고 쓰지 않는다(운영체제의 파일 대화상자는 그대로) → [[05-screen-layout\|화면 배치]] |
| 캔버스 | canvas | 다이어그램을 그리는 가운데 영역. 메뉴 바 · 툴바 · 상태 표시줄을 뺀 나머지를 모두 쓴다 → [[03-editor#1. 화면 구성]] |
| 줌 · 팬 | zoom · pan | 확대 · 축소와 화면 이동. 파일에도 실행 취소에도 들어가지 않는다 → [[03-editor#1.1 줌과 팬]] |
| 레이어 | layer | 편집 화면을 겹쳐 그리는 넷: 문서 레이어, 오버레이 레이어, 인라인 에디터, 팝업 레이어. 편집 레이어는 오버레이 레이어 · 인라인 에디터 · 팝업 레이어를 함께 부르는 말이다 → [[03-editor#1. 화면 구성]] |
| 선택 하이라이트 | selection highlight | 선택한 블록 · 범위 · 분기 라벨의 안쪽에 두르는 주황 테두리. 편집 레이어라 저장되지 않는다 → [[04-visual-design#7.1 상태 표]] |
| 호버 | hover | 마우스를 올려 둔 것. 블록에는 1px 테두리가 보이고, 블록 아이콘에는 이름과 키가 뜬다 → [[04-visual-design#7.1 상태 표]] |
| 펼침 삼각형 | disclosure triangle | 접힌 칸 앞의 `▸`, 이름 띠 앞의 `▾`. 누르면 펴고 접는다. 편집 레이어라 저장되는 그림에는 없다 → [[02-interaction-rules#접기 · 펼치기]] |
| 드래그 앤 드롭 | drag and drop | 블록이나 블록 아이콘을 끌어 다른 자리에 놓는 것 → [[02-interaction-rules#7. 드래그 앤 드롭]] |
| 드롭 위치 | drop indicator | 드래그하는 동안 놓을 자리를 보이는 표시(블록 사이의 가로줄, 블록 위의 테두리) → [[03-editor#3.2 드래그 앤 드롭]] |
| 인라인 에디터 | inline editor | 텍스트를 편집하는 동안 블록 자리에 놓이는 입력 칸 → [[03-editor#3.4 텍스트 편집]] |
| 저장 안 됨 표시 | unsaved indicator | 파일 이름 뒤의 `●`. 마지막 저장 뒤 내용이나 뷰 상태가 바뀌었다는 뜻 → [[05-screen-layout\|화면 배치]] |
| 로컬 백업 · 자동 저장 · 최근 파일 | local backup · auto save · recent files | 로컬 백업은 편집할 때마다 브라우저 저장소에 두는 사본, 자동 저장은 편집하고 2초 뒤 원래 파일에 쓰는 것, 최근 파일은 열거나 저장한 파일 열 개의 목록 → [[06-web#2. 로컬 백업과 자동 저장]], [[06-web#1.1 최근 파일]]. 예전에는 로컬 백업을 "임시 보관"이라고 적었다 |
| 문서 설정 · 환경 설정 | document settings · preferences | 문서 설정은 파일에 저장되는 것(다이어그램 › 문서 설정…), 환경 설정은 나에게만, 그 브라우저나 기기에 남는 것(파일 › 환경 설정…) → [[05-screen-layout\|화면 배치]] |
| 화면 색 | screen colors | 툴바 · 캔버스 배경 같은 편집 화면의 색. 테마가 아니며 Obsidian · 기기의 밝기를 따른다 → [[04-visual-design#2. 레이어와 출력]] |
