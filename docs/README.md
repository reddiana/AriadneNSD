# 문서

NS 차트(Nassi-Shneiderman Diagram)를 그리는 프로그램입니다. 웹(정적 페이지), Obsidian 플러그인, 데스크톱 앱을 먼저 만들고, 그 위에 Google Drive · Confluence · IDE 플러그인 · Claude skill이 붙습니다 → [[01-requirements#2. 배포 대상]].

이 폴더에는 **지금의 모습**만 둡니다: 무엇을 만드는지, 사용자에게 어떻게 보이는지, 어떻게 만드는지. 거기에 이르기까지의 결정 기록(아키텍처는 ADR, 그 밖은 DR)과 논의는 `atelier/`에 있습니다. → [[atelier/README|아뜰리에]]

## 문서 지도

폴더마다 읽는 순서대로 번호를 붙였습니다. 요구사항이 UX 설계와 아키텍처의 입력이고, 이 둘이 상세 설계의 입력입니다. 파일 형식 명세는 상세 설계에서 나옵니다. 지도의 모양은 시안 M31에서 선택했습니다(→ [[sketchbook]]).

```mermaid
flowchart LR
  R["01 요구사항<br/>무엇을 만드나"] --> U["02 UX 설계<br/>어떻게 보이고 움직이나"]
  R --> A["03 아키텍처<br/>어떤 구조로"]
  U --> D["04 상세 설계<br/>세부적으로 어떻게"]
  A --> D
  D --> S["05 명세<br/>파일은 정확히 어떻게"]
  G["06 용어집<br/>이 단어가 무슨 뜻인가"]
  A --> C["07 코딩 가이드<br/>코드를 어떻게 쓰나"]
  D --> C
```
