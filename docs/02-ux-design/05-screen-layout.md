# 화면 배치


편집 화면의 배치입니다. 웹 · 데스크톱이 같은 화면이고, Obsidian 플러그인은 편집 탭 안에 같은 툴바를 둡니다. 본보기는 [Structorizer](https://structorizer.fisch.lu/)(메뉴 바와 블록 모양 아이콘의 툴바)입니다. 정한 과정 → [[ux-decisions#W1. 웹 화면의 배치|W1]], 시안 M44 https://claude.ai/artifact/VpocjhpW3vtPJ8UHvoyFgX (사본 `journal/assets/2026-11-01-web-screen-study.html`)

![[web-screen-layout-annotated.png|800]]

![[web-screen-layout-annotated-phone.png|300]]

*MVP(2026-11-01)의 화면입니다. 위는 노트북 브라우저(1366 × 657), 아래는 휴대폰(폭 390px, 좁은 화면). 번호는 아래 글머리표의 번호와 같습니다. 툴바 아이콘(블록 아이콘 말고)의 그림은 임시입니다. 다시 찍는 스크립트 `journal/assets/2026-11-01-web-layout-annotated.mjs`(빌드한 앱을 띄워 부분마다 실제 자리에 테두리와 번호를 얹음).*

- ① **메뉴 바:** 파일 · 편집 · 다이어그램 · 보기 · 도움말. 메뉴에는 명령 이름 옆에 키를 적습니다. 데스크톱 버전은 운영체제의 메뉴 바에 같은 메뉴를 둡니다. 메뉴마다 어느 명령이 들어가는지는 [[03-editor#5.1 메뉴 구성]]에 있습니다.
- ② **파일 이름과 저장 상태:** 파일이 하나일 때(웹은 늘 하나)는 탭 줄을 두지 않고, 메뉴 바 오른쪽(데스크톱의 창 제목 자리)에 파일 이름을 둡니다. 저장 안 됐으면 이름 뒤에 `●`(VS Code · Sublime의 표시)를 붙입니다. 파일이 둘 이상이면(데스크톱 → [[01-requirements#^r-dsk|R-DSK-04]]) 툴바 아래에 편집기 탭 줄이 나타나고 이름과 `●`가 탭으로 옮겨 갑니다(macOS의 탭 창과 같습니다) → [[ux-decisions#W3. 파일 이름과 저장 상태|W3]]
- ③ **툴바 한 줄:** 파일(새로 · 열기 · 저장 · 내보내기), 되돌리기 · 다시, 잘라내기 · 복사 · 붙여넣기, ④ **블록 아이콘 여섯**(처리 · If · Case · While · For · Do-While), 감싸기 · 확대 · 예제. 창의 폭이 모자라면 다음 줄로 접힙니다(가로 스크롤을 두지 않습니다. 드롭다운이 툴바 밖으로 펼쳐져야 해서). 블록 아이콘은 블록의 모양과 색을 그대로 줄인 그림입니다. 쓰는 법 → [[02-interaction-rules#블록 아이콘으로 삽입 · 감싸기]]
- ⑤ **캔버스**가 나머지를 모두 씁니다. 노트북 브라우저(1366 × 657)에서 다이어그램에 남는 칸은 1366 × 593(세로 90%)입니다.
- ⑥ **상태 표시줄**에는 선택한 것과 알림만 둡니다. 알림은 이곳 하나에 모읍니다(`editor`의 알림도 셸의 알림도 `notify`로 → [[03-editor#6. 셸과의 연결]]). `info` 알림은 6초 뒤 사라지고, `warn` 알림(주황 글자)은 다음 알림이 오거나 `✕`로 닫을 때까지 남습니다. If ↔ Case처럼 버튼이 달린 물음도 여기에 뜹니다.
- **좁은 화면**(폭 860px 이하, 휴대폰 그림): ① 메뉴는 ☰ 하나로 접고, ③ 툴바는 두 줄로 접혀도 ④ 블록 아이콘은 남깁니다. 되돌리기 · 다시 · 감싸기 · 도움말은 화면 아래 줄로 내립니다 → [[ux-decisions#MB1. 좁은 화면|MB1]]
- ⑦ **아래 줄**(좁은 화면만): 되돌리기 · 다시 · 감싸기 ▾ · 도움말(단축키 목록)

- 메뉴 바 · 툴바 · 컨텍스트 메뉴 · 커맨드 팔레트는 모두 명령 목록 하나에서 나옵니다 → [[0033-command-list-for-shells|ADR-0033]]
- **최근 파일**([[01-requirements#^r-exp|R-EXP-04]])은 파일 메뉴의 "최근 파일 ▸"에 둡니다.
- **설정**은 창 둘로 나눕니다 → [[ux-decisions#W5. 설정|W5]]
	- **다이어그램 › 문서 설정…**: 파일에 저장되는 것(블록 텍스트의 언어, 헤더 모양, 결과 기호, 테마). 파일을 받은 다른 사람에게도 같게 보입니다. 블록 텍스트의 언어 · 헤더 모양 · 테마는 바꾸면 실행 취소의 대상입니다. 결과 기호는 뷰 상태라 대상이 아닙니다([[01-model#2. 뷰 상태]], [[ux-decisions#Q9. 실행 취소의 대상 (R7)|Q9]]). 모델의 `settings`와 `view` → [[01-model]]
	- **파일 › 환경 설정…**(`Ctrl`+`,`): 나에게만, 그 브라우저나 기기에 남는 것(화면 언어, 자동 저장, 키 힌트, 고정폭 글꼴). 셸의 `SettingsStore`입니다.
	- **보기** 메뉴: 확대 · 축소, 접기 영역 보기처럼 그 자리에서 켜고 끄는 뷰 상태
- **커맨드 팔레트**([[01-requirements#^r-edit|R-EDIT-24]]): `Ctrl`+`Shift`+`P` · `F1`로 편집 화면 위쪽 가운데에 여는 창입니다. 규칙 → [[02-interaction-rules#커맨드 팔레트]], [[ux-decisions#W6. 명령 찾기|W6]]
- **도움말**([[01-requirements#^r-edit|R-EDIT-21]]): 도움말 메뉴에 "사용법"(새 탭으로 여는 한 페이지, 배포한 사이트의 `/manual/`. 본보기는 SequenceDiagram.org의 Instructions), "단축키 목록"(`?` 키로 편집 화면 위에 키 표 모달, `Esc`로 닫음), "예제…"(아래), "이 버전에서 바뀐 것", "AriadneNSD에 대하여"를 둡니다. VS Code · IntelliJ도 문서는 브라우저로, 단축키는 따로 한 장으로 보입니다 → [[ux-decisions#W4. 도움말|W4]]
- **예제**([[01-requirements#^r-edit|R-EDIT-25]]): 예제 열 개를 쉬운 것부터 놓습니다: 병합 정렬 · 다익스트라 최단 경로 · UART 명령(Case) · 타이머 인터럽트 · 이진 탐색 · 퀵소트 · 미로 찾기 · 자판기 · 엘리베이터 · Raft 합의. 예제는 새 문서로 열립니다 → [[ux-decisions#12. 예제 (2026-11-01)|EX1 ~ EX4]]
	- **예제 모달:** 4 × 3 격자에 예제 열 개의 카드(썸네일 · 이름 · 무엇을 보여 주는지 한 줄)와 "빈 문서로 시작" · "파일 열기…" 카드. 처음 온 사람에게 한 번 뜨고(제목 "AriadneNSD에 오신 것을 환영합니다", 맨 아래에 "예제는 툴바의 “예제”와 도움말 › 예제…로 다시 열 수 있습니다."), 툴바의 "예제"와 도움말 › 예제…로도 엽니다(제목 "예제 열기", 안내 "예제는 새 문서로 열립니다. 지금 문서는 닫히고, 저장하지 않은 내용은 임시 보관에 남습니다.", 빈 문서 카드는 "빈 문서"). `Esc`로 닫고, 처음 온 사람이 닫거나 빈 문서를 고르면 다시 묻지 않습니다. 좁은 화면은 두 줄 격자
	- **툴바의 "예제"**: 툴바 오른쪽 끝의 버튼. 도움말 › 예제…와 같은 예제 모달(제목 "예제 열기")을 엽니다 → [[ux-decisions#EX4. 툴바의 예제는 모달로|EX4]]

웹에서만의 것(브라우저 탭 제목, 탭을 닫을 때 묻기, 툴바 아이콘의 id)은 [[06-web#7. 웹에서의 화면]]에 있습니다. 색 · 글자 · 치수는 [[04-visual-design]], 조작은 [[02-interaction-rules]]에 있습니다.
