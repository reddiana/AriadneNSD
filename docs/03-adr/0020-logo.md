# ADR-0020: 로고는 크노소스 벽화의 여인, 문자 로고는 `Ariadne’s NSD`로 한다

## 배경

제품 이름이 `AriadneNSD`로 정해진 뒤([[0019-product-name|ADR-0019]]), 저장소의 첫 화면, 데스크톱 앱의 아이콘, 웹 페이지의 파비콘, Obsidian 플러그인의 아이콘에 쓸 로고가 필요해졌다. 메인테이너는 아리아드네와 크노소스에 얽힌 옛 작품들을 영감의 재료로 모아 두었다.

## 결정 기준

- 메인테이너가 보기에 아름다울 것
- 이름(아리아드네)과 이어질 것
- 16px 파비콘에서도 알아볼 수 있을 것
- 그림의 권리가 깨끗할 것. 후원이나 광고, 유료 버전을 붙여도 문제가 없어야 한다
- 글꼴이 없는 곳(GitHub의 README)에서도 같은 모양으로 보일 것

## 검토한 대안

### Claude가 직접 그린 기호 (시안 A~D)

미궁과 실, If 블록의 갈림길, 실 한 줄, 벽화풍 옆얼굴을 좌표로 직접 그렸다.

- 장점: NS 차트와 이름을 한 그림에 담을 수 있다. 권리 문제가 없다.
- 단점: 메인테이너가 "모두 아름답지 않다"고 했다.

### 아리아드네 흉상 (시안 E)

석고 흉상 사진의 명암을 세 단계의 면으로 옮겼다.

- 장점: 실제 작품에서 온 얼굴이라 자연스럽다.
- 단점: 바탕이 판매용 상품 사진이었고, 같은 조각의 공개 사진을 찾지 못했다. 작은 크기에서 얼굴이 뭉개진다. 이 조각은 요즘 디오니소스로 보는 쪽이 많다.

### 크노소스 벽화 "푸른 옷의 여인들"의 가운데 여인 (시안 F)

벽화의 색 면을 그대로 벡터로 옮겼다.

- 장점: 처음부터 평평한 색 면으로 그린 그림이라 아이콘으로 옮겨도 잃는 것이 적다. 아리아드네는 크노소스의 공주라서 이름과 그림이 같은 곳에서 나온다. 메트로폴리탄 미술관이 CC0로 공개한 사진이 있다.
- 단점: NS 차트가 보이지 않는다. 섬세한 그림이라 아주 작은 크기에는 따로 줄인 판이 필요하다.

### 문자 로고의 표기

- 붙여 쓴 `AriadneNSD`: 공식 이름과 같아서 헷갈리지 않는다. 뜻이 드러나지 않는다.
- `Ariadne’s NSD`: "Ariadne's Thread"(아리아드네의 실)를 떠올리게 한다. 공식 이름과 표기가 달라진다.

## 결정

**그림 로고는 크노소스 벽화 "푸른 옷의 여인들"의 가운데 여인으로 하고, 문자 로고는 `Ariadne’s NSD`로 적는다.**

- **그림 로고:** 주홍 바탕에 검은 머리와 석고색 얼굴. 32px부터는 벽화의 모습 그대로 쓰고, 16~24px에서는 머리·얼굴·눈만 남긴 작은 판을 쓴다. 눈과 눈썹은 벽화의 자리에 또렷한 선으로 다시 그린다.
- **바탕 그림:** 메트로폴리탄 미술관이 CC0로 공개한 Emile Gilliéron의 모사화 사진을 쓴다.
- **문자 로고:** `Ariadne`는 먹색 GFS Didot, 소유격 `’s`는 주홍의 기울인 글씨로 조금 작게, `NSD`는 주홍의 Josefin Sans로 적는다. 글자는 윤곽선으로 바꿔 넣는다.
- **표기:** 글로 적는 이름은 언제나 `AriadneNSD`다. `Ariadne’s NSD`는 문자 로고 그림에서만 쓰고, 그림의 대체 글자도 `AriadneNSD`로 둔다.

아름다움과 이름과의 연결을 NS 차트가 보이는 것보다 앞에 두었다. 메인테이너가 여러 시안을 직접 보고 골랐다.

바탕 그림의 출처, 만든 과정, 견주어 본 시안은 [[logo-source]]에 있다.

## 결과

- 좋아지는 점: 저장소와 제품에 얼굴이 생긴다. 권리가 깨끗한 바탕에서 나왔고, 사진을 바꿔 다시 뽑을 수 있는 스크립트가 있다.
- 감수하는 점: 로고만 봐서는 NS 차트 편집기인 줄 알 수 없다. 로고의 표기(`Ariadne’s NSD`)와 공식 이름(`AriadneNSD`)이 달라서 소개 글에서 표기가 갈릴 수 있다. 그리스의 문화재법이 닿을 가능성은 낮다고 보았으나 법률 자문을 받은 것은 아니다.
- 후속 작업: Obsidian 리본용 단색 아이콘, 데스크톱 아이콘 파일, 파비콘 파일을 만든다.
