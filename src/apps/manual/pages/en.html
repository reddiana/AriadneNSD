5-minute tour

Draw a Nassi–Shneiderman diagram that sums an array and takes the average, starting from an empty document. The keyboard alone or the mouse alone is enough. In the key tables the left column is the Vim key, the right one the standard key and the mouse. Use whichever your hands know.

Open the app and you see a new document with one empty block selected. The menus and the toolbar are on top; the status bar at the bottom tells you what is selected.

1Write the first block

To write in the selected block, start editing. When you are done, press Enter to accept. Esc also keeps what you wrote.

→
To Vim key Standard key · mouse
Start editing i (cursor at the start), cc (clear and write) Enter, F2, double-click
Accept Esc Enter
New line inside a block Shift+Enter

While a block is selected, letter keys are commands, not text (as in Vim). Start editing first to write.

2Add more blocks

A new block goes after the selected one. Adding a process block starts editing right away, so write, press Enter, add, and write again. Hold Shift to add before instead.

→
To Vim key Standard key · mouse
Add a process block after / before and write o (or a p) / O The process block icon on the toolbar / Shift+click
Move between blocks j k ↓ ↑, click

3Wrap in a While

Put the last two blocks, sum ← sum + a[i] and i ← i + 1, in a loop.

  1. Select both blocks. With i ← i + 1 (the block you just wrote) selected, press Shift+↑ once: the block above joins the selection and the orange frame goes around both. With the mouse, click sum ← sum + a[i], then Shift+click i ← i + 1.
  2. Wrap them in a While. Press s, then w. With the mouse, Ctrl+click the While icon on the toolbar.
  3. Write the loop condition. Editing starts right away: write i < n and press Enter.
→ →

The same, on the whole screen. After s, wait a moment: a hint of the next keys appears just under the selection.

To Vim key Standard key · mouse
Select several blocks V, then j k Shift+↑ ↓, Shift+click

Unwrap ds The context menu (right-click)

For two-key commands, press the first key and wait a moment: the keys you can press next appear just under the selected block. No need to memorize them.

4Add an If

Add an If after the loop and write its condition. Then go down into the empty block of the true branch and write the average. The ∅ in the false branch means "nothing here".

5Save

Saving writes a .ns.svg file. The file is a picture in itself, so browsers, GitHub and documents show it as is, and AriadneNSD opens it again for editing.

The dot (●) next to the file name at the top right means there are unsaved changes.

To Vim key Standard key · mouse
Save / Save As Ctrl+S / Ctrl+Shift+S, the save icon on the toolbar
Undo / Redo u / U Ctrl+Z / Ctrl+Y
See every key ? Help › Keyboard Shortcuts

In Chrome and Edge, a file saved once is then saved automatically. In Firefox and Safari, each save downloads the file. Unsaved work is also kept in the browser: when you open the page again, it asks whether to restore it.
