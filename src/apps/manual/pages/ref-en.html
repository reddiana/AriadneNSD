The screen

  • Menu bar: File · Edit · Diagram · View · Help. Every command is here, with its key next to it if it has one.
  • Toolbar: New · Open · Save · Export, Undo · Redo, Cut · Copy · Paste, five block icons (Process · If · Case · While · Do-While), Wrap, Zoom, Examples.
  • Canvas: where you draw. Several diagrams are laid out automatically.
  • Status bar: what is selected, and messages. The ● next to the file name at the top right means unsaved changes.

Blocks

Write anything in a block: code or plain sentences. Text does not wrap by itself; break long lines with Shift+Enter. The ∅ in an empty cell means "nothing here".

Block Meaning Kind letter
Process One step of work p (after a only, same as o)
If Two branches, true and false i
Case Several branches by value; default comes last k
While Checks the condition first, then repeats w
For Repeats a set number of times (looks like While; the text tells them apart). Not on the toolbar: use keys or menus f
Do-While Runs once, then checks the condition d
Call Calls a Method of the same document c

Kind letters follow the insert keys (a A) and the wrap key (s).

Adding blocks and editing text

A new block goes after the selection, or before it with Shift. If an empty block (∅) is selected, the new block takes its place. Editing the text (or condition) starts right away.

Press a and wait a moment: the next letters appear just under the selection.

Moving, copying, deleting

Moving swaps the selection with the block above or below. Moving past the end takes it out of the block that holds it. To put it inside another block, drag it there, or cut and paste. Text copied from another program pastes as one process block per line.

Wrapping, unwrapping, adding branches

Wrapping puts the selected blocks in a new control block (an If's true branch, a Case's first branch). Unwrapping removes the shell and keeps what is inside. Add and delete a Case's branches like blocks, with its label selected. The default branch always comes last.

→
To Vim key Standard key · mouse
Wrap s + kind letter Ctrl+click a block icon, "Wrap" on the toolbar, or drop the icon on the blocks
Unwrap (the nearest control block around the selection) ds The context menu
Add a branch after / before (label selected) o / O
Delete a branch (label selected) x Delete
Edit a branch label (anywhere in the branch) L Double-click the label

Adding a branch at an If's label asks whether to turn it into a Case. Swapping an If's true and false branches keeps the condition, so the meaning changes: fix the condition.

Events, Methods and several diagrams

A document can hold several diagrams. With a header a diagram becomes an Event (something started from outside, like an interrupt or a timer) or a Method (something a call block calls). The layout is automatic: Events on the left, Methods on the right. A call block's name follows the Method's header; each call block has its own arguments and result.

Files

AriadneNSD runs in the browser without a server. Your files stay on your computer. A saved .ns.svg is a picture in itself, so it shows anywhere, and opening it again lets you keep editing.

  • Open: the File menu, the toolbar, or drop a file on the page. Opens .ns.svg and .ns.
  • Save: Ctrl+S; Save As is Ctrl+Shift+S. Chrome and Edge write to the original file and save automatically after the first save. Firefox and Safari download the file on each save.
  • Recent Files: in the File menu, up to ten files you opened or saved.
  • Local backup: unsaved work is kept in the browser; when you open the page again, it asks whether to restore it.
  • Export as PNG: File › Export. It looks the same as the saved picture.
  • Examples: "Examples" on the toolbar or Help › Examples… opens ten of them. An example opens as a new document, so feel free to change it.

AriadneNSD is not 1.0 yet. Files you save now may not open in later versions.

Reporting a problem

If something behaves oddly or a drawing is wrong, please tell us. Say what you did (keys, clicks), what you expected and what happened. Add the version from Help › About AriadneNSD and your browser and OS.

  • In public: GitHub issues, where others can see and confirm it.
  • In private: if you would rather not share your diagram, email report@ariadnensd.com. Attach the .ns.svg only if you want to.
