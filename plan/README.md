# 계획과 세션 기록

메인테이너와 Claude가 의논하고 계획을 세우는 과정을 정리하는 곳입니다.
애플리케이션 자체에 대한 문서(요구사항, 아키텍처, ADR, 설계)는 `docs/`에 있습니다. → [[docs/README|문서 색인]]

## `docs/`와의 차이

| | `docs/` | `plan/` |
| --- | --- | --- |
| 대상 | 애플리케이션 | 우리가 일하는 과정 |
| 내용 | 확정된 요구사항·결정·설계 | 논의, 검토 중인 생각, 계획, 할 일 |
| 수명 | 제품과 함께 계속 유지 | 세션 기록은 쌓이고, 계획은 진행에 따라 갱신 |

논의 끝에 결정이 나면 그 결과는 `docs/`(요구사항 또는 ADR)에 반영하고, 여기에는 링크만 남깁니다.

## 구성

| 위치 | 내용 |
| --- | --- |
| [[status]] | 지금 하고 있는 일, 다음에 할 일, 열린 질문 |
| [[debt]] | 아직 처리하지 못한 결정 요청, 확인받지 못한 보고, 미뤄 둔 일 |
| [[inbox]] | 세션 사이에 메인테이너가 생각을 적어 두는 페이지. 세션을 시작할 때 함께 검토 |
| `sessions/` | 작업 세션마다 하나씩: 논의한 것, 결정한 것, 다음 할 일 |
