## 프로토타입
### 추가/변경 요건
- `O`의 사용법이 혼란스럽습니다. 지금 넣을 위치가 `뒤`인지, `앞`인지, `안쪽`인지 알 수가 없어요. `안쪽`이고 처리블록이 선택되었을 때 `P`하면 동작이 없는 것 같아요. 사용하면서 혼란스럽습니다.
- 선택영역 + `E`는 추가 선택없이 "고른 블록을 새 다이어그램으로 빼고 이벤트 달기(그 자리에는 호출 블록)"으로 동작
- 접기 상태를 더블클릭하면 펼치기
- 좌우방향키로는 다이어그램간 이동 하면 안됨: 
	- 헤드에서라면 지금처럼 가능
	- Ctrl + Shift + 좌우방향키로 이동 가능하게 할 것
- Ctrl + 상하방향키: 
	- 컨트롤 블록 내부라면 컨트롤 블록의 위아래 블록으로 이동
	- 일반 블록이라면 그냥 위아래 블록으로 이동
- Ctrl + 좌우방향키: 
	- IF나 Case 내부라면 좌우 옆 브랜치로
	- 일반 블록이라면 그냥 위아래 블록으로 이동
- 호출 블록을 다른 이벤트/메소드를 호출하는 것으로 변경하는 방법 필요
	- 호출 블록에서의 수정은 이벤트 이름바꾸기가 아니라 호출할 이벤트 선택이 편할 것 같음
- 이벤트 헤드에 같은 이름 불가하게 해야함
