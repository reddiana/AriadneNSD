# 2026-10-10 로고 시안

같은 날 여섯 번째 세션이다 (← [[2026-10-10-05-product-name]]). 이름 바꾸기의 뒷정리를 확인하고, inbox에 남아 있던 로고 항목으로 시안을 여러 판 만들었다. 저장소 맨 위 `README.md`에 그림 로고와 문자 로고가 들어갔다.

## 논의 흐름

1. **이름 바꾸기 확인.** 메인테이너가 자기 몫을 제대로 했는지 물었다. GitHub 저장소 이름, 로컬 폴더, Claude Code 메모리 폴더는 되어 있었다. Obsidian의 볼트 목록에는 옛 경로만 남아 있었다. 로컬의 원격 주소는 Claude가 새 주소로 고쳤다.
2. **첫 시안 A~D.** Claude가 좌표를 직접 적어 네 가지를 그렸다(미궁과 실, 갈림길, 실 한 줄, 크노소스의 옆얼굴). 메인테이너의 답은 "모두 아름답지 않네요"였다.
3. **다른 도구.** 다른 LLM을 추천해 달라는 물음에, Claude는 이미지 생성 모델(Midjourney, ChatGPT의 이미지 생성, Recraft)을 권하고 처음 넣을 프롬프트를 적어 주었다.
4. **흉상(E).** 메인테이너가 inbox의 아리아드네 흉상을 바탕으로 해 보라고 했다. Claude는 선을 지어내지 않고 사진의 명암을 세 단계의 벡터 면으로 옮겼다. 머리띠를 주황으로 칠해 실로 삼았으나 메인테이너가 "실타래와 관계없다"고 해서 뺐다.
5. **공개 사진.** 흉상의 공개 사진을 찾아보았다. Wikimedia Commons에서 찾은 카피톨리노의 "Arianna" 사진은 inbox의 흉상과 다른 조각이었다. inbox의 흉상은 요즘 디오니소스로 보는 쪽이 많다는 것도 알게 되었다.
6. **벽화의 여인(F).** 메인테이너가 크노소스 벽화의 가운데 여인으로 "고대 에게해 여인의 아름다움"을 주제로 삼자고 했다. 벽화의 색 면을 그대로 벡터로 옮겼다. 메인테이너가 주홍 바탕을 골랐다.
7. **눈과 작은 크기.** 큰 그림에서도 눈이 뭉개진다는 지적에, 눈 둘레를 키워 자리를 재고 눈만 또렷한 선으로 다시 그렸다. 작은 크기용으로 덩어리만 남긴 판을 두 가지 만들었고, 메인테이너가 32~48px은 "이전 것을 그대로" 쓰자고 해서 16~24px용 하나만 남겼다.
8. **저장소 정리.** 메인테이너가 "결과를 우리 repo에 정리했나요?"라고 물었다. 그때까지 Claude는 파일만 만들어 두고 커밋하지 않았고, 그림을 뽑은 스크립트는 임시 폴더에만 있었다. 물음을 받고 나서 옮기고 커밋했다.
9. **README.** 그림 로고와 문자 로고를 저장소 맨 위 `README.md`에 넣었다.

## 발견한 위험

- **Claude가 지어낸 그림은 아름답지 않았다.** 좌표를 글자로 적어 그리는 방식은 구조는 잡아도 선이 어색하다. 실제 작품의 사진을 색 면이나 명암으로 옮기자 결과가 크게 나아졌다. → [[logo-and-icon-assets]]
- **바탕 사진의 출처를 모른다.** 벽화 시안은 inbox에 붙여 넣은 그림에서, 흉상 시안은 판매용 상품 사진에서 뽑았다. 벽화는 고대 작품이지만, 실제로 쓰기 전에 공개 사진으로 다시 옮겨야 한다. 이 상태로 README에 넣었고 push하면 공개된다는 것을 메인테이너에게 알렸다.
- **그리스의 규정을 확인하지 않았다.** 박물관 소장품 이미지를 상업적으로 쓸 때 허가를 요구하는 법이 있다고 Claude가 아는 대로 말했을 뿐, 조문은 보지 않았다.
- **Claude는 물어야 정리했다.** 시안 파일을 만들고도 커밋하지 않았고, 스크립트는 세션이 끝나면 사라지는 임시 폴더에 두었다.
- **확인하지 못한 화면.** 시안 페이지는 밝은 화면의 윗부분만 찍어 보았다. README가 GitHub에서 어떻게 보이는지, 어두운 테마에서 문자 로고가 바뀌는지는 push 뒤에야 볼 수 있다.
- **중간 판의 진주는 지어낸 것이었다.** 32~48px용 판의 굵은 진주 여덟 알은 벽화가 아니라 Claude가 자리를 정해 찍었다. 그 판은 쓰지 않기로 했다.

## 마무리 뒤 (2026-10-11)

마무리하고 push한 뒤에 메인테이너가 두 가지를 더 요청했다.

1. **공개 사진 확인.** "조금 걱정되네요. 공개 사진으로 거의 동일한 사진이 있을 것 같아요. 확인해주세요." Wikimedia Commons에서 같은 벽화의 사진을 찾았다. 메트로폴리탄 미술관이 CC0로 공개한 `Reproduction of the "Ladies in Blue" fresco MET DP234770.jpg`(Emile Gilliéron의 모사화, 3905×2451)이다. 이 사진으로 로고를 다시 뽑았다. 구도는 거의 같고, 사진이 커서 진주 줄이 더 또렷하다.
2. **inbox 사진 삭제.** "기존 inbox의 사진들은 github에 울리는게 문제될 수 있겠네요. 모두 삭제해주세요." 저장소 맨 위에 있던 `Pasted image ….png` 9개를 지우고, inbox의 그림 줄을 지웠다. 제목 두 개는 남겼다. git 기록에는 사진이 남아 있다. 기록에서까지 지우려면 기록을 고쳐 쓰고 강제로 push해야 해서, 메인테이너의 확인을 받기로 했다.

3. **그리스 법.** "뉴욕에 있는 모사화의 사진을 베이스로 로고를 만들어도 그리스 박물관 허가를 받아야한다구요?" Claude는 허가가 필요하다고 보지 않는다고 답했고, 해설 글을 찾아본 뒤 "닿을 가능성 낮음, 그리스 안에서 사업할 때만 다시 봄"으로 낮춰 적었다. → [[logo-source#남은 확인]]
4. **문자 로고.** 메인테이너가 공식 이름은 `AriadneNSD`로 두고 문자 로고에서만 `Ariadne's NSD`로 적자고 했다. "Ariadne's Thread를 연상하게 하고 싶습니다." Claude는 찬성하고 시안 세 가지(W1~W3)를 보였고, 메인테이너가 Claude의 추천(W3: 소유격을 주홍으로)을 받았다. 표기 규칙은 CLAUDE.md에, 근거는 [[0019-product-name|ADR-0019]]의 "이후 변경"과 [[logo-source#문자 로고]]에 적었다.
5. **문자 로고 다듬기.** 메인테이너가 세 차례 더 요청했다: 소유격은 필기체에 가깝게 작게 하고 `NSD`는 고정폭이 아닌 글자로 크게(W4~W6 가운데 W4), `NSD`의 글꼴을 바꿔 보기(일곱 가지 가운데 W4-5 · W4-6), `NSD`의 자간을 좁히기(여섯 가지 가운데 Claude의 추천 W4-6b). README의 문자 로고를 W4-6b로 바꿨다. → [[logo-source#문자 로고]]
