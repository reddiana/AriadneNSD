# 2026-10-10 inbox 검토

메인테이너가 잠깐 들어와 inbox 항목을 하나씩 결정한 세션. inbox 10개 항목을 모두 처리했다. 같은 날 세 번째 세션이다 (← [[2026-10-10-02-prototype]]).

## 논의 흐름

1. 세션 시작 요약을 보여 드림. 메인테이너: "지난 세션 요약은 다음 세션에 그대로 다시 보여주세요." → [[status]] 맨 위 절을 지우지 않고 남김.
2. inbox를 항목마다 질문 하나씩(선택지와 추천)으로 결정. 결정 하나마다 반영하고 커밋했다.
3. 세션 기록 이름 → activation bar·"질문" 범위(결정 없이 처리) → #P3 신설 → 웹 광고 → Claude skill → 후원 링크 → 문제 알리기 → 드래그 이동 → 용어·inbox 형식 순서로 처리.
4. 문제 알리기는 Claude가 GitHub 이슈로 보내자고 했으나, 메인테이너가 쓸모없는 이슈가 쌓일 것을 걱정해 Discussions(양식) + 비공개 채널 + FAQ로 바꿈.

## 결정

- 세션 기록 파일 이름에 그날의 순번을 넣는다: `YYYY-MM-DD-NN-주제.md`. 기존 네 파일 이름을 바꾸고 링크를 고쳤다. 규칙은 CLAUDE.md "세션 끝날 때 할 일"에 반영했다.
- Sequence Diagram에 activation bar를 넣는다. 기존 두 그림(`drive-app-basics`, `02-architecture`)에 넣고, CLAUDE.md 문서 작성 규칙에 추가했다.
- inbox의 "5. 질문"은 Claude에게 하는 모든 질문이다. inbox 맨 위 주석을 고쳤다.
- 요구사항 우선순위에 #P3(언젠가, 하면 좋음)을 새로 둔다. inbox의 "#후순위"는 #P3로 적는다.
- 웹 광고 #P3: 편집 화면을 가리지 않고, 저장·내보내기·공유 때만 보인다. 정확한 자리는 광고 네트워크 정책을 확인해 정한다 → [[01-requirements#^web-ads]]
- Claude skill #P3: `.ns.svg` 파일과 공유 URL을 함께 내놓는다 → [[01-requirements#^skill-claude]]
- Buy Me a Coffee #P3: 모든 무료 배포 대상에 둔다 → [[01-requirements#^all-donate]]. README 버튼은 웹 베타를 출시할 때 단다 (status에 올림)
- 문제 알리기 #P3: 실행 환경, 로그(오류 스택, 불변 조건 실패, 파일 입출력 실패), 최근 편집 기록, 동의 시 다이어그램을 담은 보고서. 오류가 나면 알릴지 묻는다 → [[01-requirements#3.7 문제 알리기]]
	- 보내는 길: Claude가 처음에 GitHub 이슈로 제안했으나, 메인테이너가 "어설프거나 단순 착각한 이슈들이 등록될 것이 우려됩니다"라고 함. 공개는 GitHub Discussions(양식으로 거름), 비공개는 이메일·폼. 이슈는 메인테이너만 만든다
	- 비공개 보고는 다른 사용자가 볼 수 없다는 단점에 대해, 메인테이너: "비공개로 같은 문제가 여러번 들어오면 FAQ 페이지에 정리하겠습니다."
- 드래그로 옮기기: 요구사항 [[01-requirements#^edit-dnd]]를 "블록 하나 또는 선택한 블록들"로 넓히고, 프로토타입에 넣는다 (status에 올림)
- 용어: "선택 범위" → "선택 영역", "이름 붙은 범위" → "이름 붙은 영역". 요구사항·용어집을 고쳤다. 승인된 ADR(0015~0017)과 지난 세션 기록은 그대로 두고, 용어집에 옛 이름을 적었다. 프로토타입 화면 글자는 다음에 프로토타입을 고칠 때 바꾼다
- inbox 1레벨 제목에 `6. 기타`를 더하고, 항목은 글머리표로 적어도 된다. CLAUDE.md와 inbox 주석에 반영했다

## 발견한 위험

- 광고 네트워크(예: Google AdSense)는 팝업·대화 상자 안의 광고를 정책으로 막는 경우가 많다. "저장·내보내기·공유 때만 광고"가 그대로 되지 않을 수 있다 → [[01-requirements#6. 미결정 사항]]
- 세션 기록 이름을 바꿀 때 sed 일괄 치환이 inbox 원문과 지난 세션 기록 속 git 출력까지 바꿨다. 바로 되돌렸다. 원문·기록을 일괄 치환할 때는 범위를 좁혀야 한다.
