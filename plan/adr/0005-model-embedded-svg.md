# ADR-0005: 모델 내장 SVG를 저장 형식으로 사용

## 배경

다이어그램을 저장할 파일 형식을 정해야 한다. Obsidian 노트에 그림을 바로 넣어 보고 싶고, 다시 열어 편집도 할 수 있어야 한다. [drawio-obsidian](https://github.com/zapthedingbat/drawio-obsidian)은 SVG 안에 다이어그램 정보를 넣어 저장하는데, 이 방식이 마음에 든다.

## 결정 기준

- 플러그인이 없어도 어디서나 그림으로 보여야 한다. ([[01-requirements#^obs-embed]], [[01-requirements#^fmt-svg]])
- 같은 파일을 다시 열어 편집할 수 있어야 한다.
- 파일 하나로 관리되어야 한다 (그림과 원본이 따로 놀지 않도록).

## 검토한 대안

### 원본 파일(JSON 등) + 이미지 내보내기

- 장점: 원본 형식이 단순
- 단점: 파일이 두 개, 원본을 고치고 내보내기를 잊으면 그림과 원본이 달라짐, 노트에 바로 넣을 수 없음

### 그림만 SVG로 저장하고 열 때 그림을 역해석

- 장점: 파일 하나
- 단점: 역해석이 불안정하고, 다른 도구가 고친 SVG를 해석할 수 없음

### 모델 내장 SVG

- 장점: 파일 하나가 그림이자 원본, 어떤 SVG 뷰어에서도 보임
- 단점: 다른 도구로 그림만 고치면 다시 열 때 사라짐, 파일이 조금 커짐

## 결정

저장 파일은 **SVG**이고, 다이어그램 모델을 SVG의 `<metadata>` 안에 넣는다.

- **모델이 원본이다.** 열 때는 모델만 읽고, 저장할 때마다 그림 부분을 모델에서 새로 만든다.
- 모델이 없거나 손상된 SVG는 편집 불가로 처리한다. 그림을 역해석하지 않는다.
- 세부 형식은 [[01-file-format]]에 정의한다.

## 결과

- 좋아지는 점: Obsidian 노트, 브라우저, 문서 도구 어디서나 그림이 보인다. git에 파일 하나로 관리된다.
- 감수하는 점: 다른 SVG 편집 도구로 그림만 고친 내용은 보존되지 않는다.
