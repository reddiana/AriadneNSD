5분 둘러보기

배열의 합과 평균을 구하는 NS 차트를 처음부터 그려 봅니다. 키보드만으로도, 마우스만으로도 됩니다. 키는 왼쪽이 Vim 키, 오른쪽이 표준 키와 마우스입니다. 둘 중 손에 익은 쪽을 쓰면 됩니다.

앱(reddiana.github.io/AriadneNSD/app/)을 열면 빈 블록 하나가 선택된 새 문서가 보입니다. 위에는 메뉴와 툴바가, 아래에는 지금 선택한 것을 알려 주는 상태 표시줄이 있습니다.

1첫 블록 적기

선택한 블록에 글자를 적으려면 편집을 시작합니다. 적고 나서 Enter를 누르면 받아들입니다. Esc도 적은 대로 받아들입니다.

→
하는 일Vim 키표준 키 · 마우스
편집 시작i (글자 앞에 커서), cc (비우고 새로)Enter, F2, 더블클릭
받아들이기EscEnter
블록 안에서 줄 바꾸기Shift+Enter

블록이 선택된 채로 글자 키를 누르면 글자가 적히지 않고 명령이 됩니다(Vim과 같습니다). 적으려면 먼저 편집을 시작하세요.

2블록 더 넣기

새 블록은 선택한 블록의 뒤에 들어갑니다. 처리 블록을 넣으면 바로 편집이 시작되니, 적고 Enter, 다시 넣고 적기를 되풀이합니다. 앞에 넣으려면 Shift를 함께 누릅니다.

→

처리 블록을 뒤 / 앞에 넣고 바로 적기o / O툴바의 처리 블록 아이콘 / Shift+클릭
블록 사이를 오가기j k↓ ↑, 클릭

3While로 감싸기

아래 두 블록을 반복문 안에 넣습니다. 먼저 두 블록을 함께 선택하고, 감쌀 블록의 종류를 고릅니다. 감싸면 반복 조건의 편집이 바로 시작됩니다.

마지막 블록에서 Shift+↑ → s를 누르면 화면 아래에 다음 키의 힌트가 뜸 → w → 조건 i < n을 적고 Enter

두 글자 명령은 첫 키를 누르고 잠깐 기다리면 화면 아래에 다음에 누를 수 있는 키가 보입니다. 외우지 않아도 됩니다.

4If 넣기

반복문 뒤에 If를 넣고 조건을 적습니다. 그다음 참 분기의 빈 블록으로 내려가 평균을 적습니다. 거짓 분기의 ∅는 "여기는 비어 있음"이라는 표시입니다.

5저장하기

저장하면 .ns.svg 파일이 생깁니다. 이 파일은 그 자체로 그림이라 브라우저, GitHub, 문서에 그대로 보이고, AriadneNSD로 다시 열면 이어서 고칠 수 있습니다.
