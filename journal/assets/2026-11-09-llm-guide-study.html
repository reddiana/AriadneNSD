M56 LLM · 에이전트 안내서 시안

다른 LLM(Grok, ChatGPT, 다른 Claude)이 "ariadnensd.com으로 버블 정렬을 그려 주세요"를 받았을 때 바로 열리는 링크를 줄 수 있게 하는 안내서(/llms.txt)의 초안과, 그 초안만 준 새 모델들로 해 본 실험입니다. 2026-11-09.

메인테이너(inbox): "예를들어 Grok이나 ChatGPT같은 다른 LLM에게 또는 다른 claude에게 "https://ariadnensd.com 으로 버블소트 알고리즘을 nsd로 그려주세요"라고 했을 때, 그 LLM들에게 도움이 되려면 무엇을 준비해야될까요? LLM과 에이전트를 위한 안내서를 웹 버전에 포함시킬 수 있나요?"
메인테이너(덧붙임): "다른 에이전트에게 안내할 때, '공유 링크 복사' 기능을 추천해주세요."

  • 열쇠는 사람이 읽을 수 있는 꾸림 u입니다. 지금의 d(deflate)는 코드 없이 만들 수 없고, j(base64)는 손으로 만들기 어렵습니다. u는 앱에 아직 없으므로 실험에서는 브라우저와 같게 읽는 검사 스크립트로 열었습니다. 앱에 더하는 일은 짧습니다(읽기만, LG2).
  • "공유 링크 복사"를 기준으로 삼았습니다. 안내서는 LLM에게 "앱의 파일 › 공유 링크 복사가 만드는 것과 같은 공유 링크를 주라"고, 사용자에게는 "고친 뒤 파일 › 공유 링크 복사로 새 링크를 만들어 다시 넘기라"고 안내하게 합니다. 거꾸로 사용자가 준 d 링크는 코드를 못 돌리는 모델이 풀지 못하는데, 두 모델 모두 지어내지 않고 파일을 청했습니다. 코드를 돌리는 모델은 d를 풀어 고치고 새 d 링크를 냈습니다.
  • 안내서는 영어로 썼습니다(LG1의 까닭). 시안의 글은 한국어입니다.

왜 필요한가

다른 LLM은 AriadneNSD의 화면을 조작하지 못합니다. 할 수 있는 것은 글을 내놓는 것뿐입니다: 링크, 파일, 코드 블록. AriadneNSD의 공유 링크는 문서 전체를 URL의 # 뒤에 담으므로(ADR-0043), LLM이 그 형식을 알면 서버도 계정도 없이 "누르면 열리는" 결과를 줄 수 있습니다.

그런데 지금 LLM이 https://ariadnensd.com을 읽으러 오면 보이는 것은 AriadneNSD 불러오는 중… · Loading… 한 줄입니다(앱이 자바스크립트로 그려지는 SPA). 형식을 알려 주는 곳이 없습니다. 그래서 준비할 것은 셋입니다.

  1. 안내서 /llms.txt: 모델 JSON의 짧은 설명, 블록 종류, 규칙, 예제, 링크 만드는 법, 사용자가 준 링크를 읽는 법(llmstxt.org의 관례). 첫 화면 HTML에서 이것을 가리킵니다.
  2. LLM이 손으로 쓸 수 있는 링크 꾸림 #ns1.u.<encodeURIComponent(JSON)>.
  3. (덤) 모델 JSON의 JSON Schema: 도구 호출(구조화 출력)을 쓰는 에이전트용.

u · j · d: 링크에 문서를 담는 방식

공유 링크는 https://ariadnensd.com/#ns1.d.…처럼 생겼습니다. ns1은 링크 형식의 판, 가운데 글자 하나가 꾸림(담는 방식), 그 뒤가 문서입니다. 셋 모두 안에 든 것은 같은 문서(모델 JSON)이고 담는 모양만 다릅니다.

글자뜻링크의 모습지금 앱LLM이 손으로
ddeflate: 압축한 뒤 base64로#ns1.d.fZLPSgMx… (가장 짧음)공유 링크 복사가 만드는 것. 읽음못 만듦 (압축에 코드가 필요)
jJSON: 압축 없이 base64로만#ns1.j.eyJuYW1l… (약 2배)읽음 (압축을 못 하는 브라우저용)어렵고 틀리기 쉬움
uURL 인코딩: JSON을 그대로, 특수문자만 %7B 같은 글자로#ns1.u.%7B%22name%22… (약 3배)아직 없음, 새로 제안 (LG2)만들 수 있음 (실험에서 확인)

실험

이 저장소를 모르는 새 서브에이전트(Claude haiku · sonnet · opus)에게 안내서 초안 파일 하나만 읽게 하고(다른 파일 · 웹 금지), 채팅 창의 LLM처럼 코드를 돌리지 말고 답하게 했습니다. 하나씩은 코드 실행을 허락해 ChatGPT의 Python 도구 같은 경우를 흉내 냈습니다. 답은 사용자에게 보이는 그대로(markdown) 파일로 저장하게 하고, 검사 스크립트 journal/assets/2026-11-09-llm-guide-check.mjs가 그 답에서 링크를 채팅 앱처럼 떼어 내(markdown 링크는 괄호의 짝까지) 앱과 같은 parseModel로 열었습니다(j · d는 앱의 readShareLink, u는 new URL(link).hash → decodeURIComponent). 통과한 것은 앱의 렌더러(renderDoc + 서브셋 글꼴)로 그림을 만들고, 지금의 j · d 꾸림으로 실제 링크를 만들었습니다. 그 링크는 journal/assets/2026-11-09-llm-guide-open.mjs가 로컬 앱(pnpm dev, 5173)에서 Playwright로 열어 보기 모드에 그림이 나오는 것을 확인했습니다(서버는 끝나고 껐습니다).

과제의 말은 메인테이너의 원문 그대로입니다: "https://ariadnensd.com 으로 버블소트 알고리즘을 nsd로 그려주세요", 이진 탐색, "switch 문을 쓰는 간단한 계산기(+, -, *, /, 0으로 나누기 처리)". 덧붙인 요청을 따라 v2부터는 링크를 받아 고치는 과제를 더했습니다: 앱의 "공유 링크 복사"로 만든 버블 정렬 링크(d, 그리고 비교로 j)를 주고 "swapped 플래그를 더해 고쳐 주세요".

LG1안내서의 자리와 언어

LLM이 https://ariadnensd.com을 받으면 첫 화면 HTML을 읽습니다. 지금은 "Loading…" 한 줄뿐입니다.

실제 사례 (2026-11-09, 메인테이너가 ChatGPT에게 같은 요청을 함): "요청하신 AriadneNSD는 현재 페이지가 로딩 화면으로만 확인되어 제가 직접 다이어그램을 입력하거나 저장하지는 못했습니다."
알 수 있는 것 둘: ① ChatGPT는 첫 화면 HTML만 읽었고 /llms.txt를 찾아보지 않았다. ② 앱을 조작하려 했다. 그래서 첫 화면 HTML 안에 "조작하지 말고 공유 링크를 만들어 주라"는 말과 만드는 법의 요약이 바로 있어야 한다. 링크를 따라가지 않는 도구도 있기 때문이다.

4★ 1번 + 첫 화면 HTML 안에 짧은 안내를 바로

<!-- index.html, 앱이 뜨면 사라지는 자리 -->
<section id="for-ai" hidden>
  For AI assistants: you cannot operate this editor.
  Give the user a share link instead:
  https://ariadnensd.com/#ns1.u.<encodeURIComponent(
    {"name":"x.ns.svg","model":<model JSON>})>
  Model JSON, blocks, rules, examples: /llms.txt
  (a minimal example follows) …
</section>

사람의 화면에는 보이지 않고, HTML을 글로 읽는 도구에게만 보입니다. 예제 하나와 규칙 넷을 넣어 두 쪽(hidden 속성을 무시하는 도구, 따르는 도구) 모두에서 됩니다. 추천은 우선 이 넷째 안입니다(메인테이너의 ChatGPT 사례 뒤에 더함). 만들면 ChatGPT · Grok으로 다시 해 봅니다.

<!-- index.html -->
<link rel="alternate" type="text/markdown"
      href="/llms.txt" title="Guide for AI assistants">
<meta name="description" content="… AI assistants:
  read /llms.txt to make a share link.">

<p id="ans-boot-text">AriadneNSD 불러오는 중… · Loading…

# AriadneNSD

> AriadneNSD (https://ariadnensd.com/) is a free Nassi–Shneiderman diagram (NSD, structogram) editor that runs entirely in the browser. You cannot operate the editor, but you can hand the user a link that opens your diagram in it: the whole diagram travels inside the link, so no upload or account is needed.

This guide is for language models and agents. It tells you how to write an AriadneNSD diagram as JSON and how to turn it into a link.

## What to give the user: a share link

Give the user a share link. It is the same kind of link the app makes with File › Copy Share Link (Korean screen: 파일 › 공유 링크 복사). The user only clicks it: the diagram opens in the app in view mode, and the Edit button (편집하기) makes it editable.

1. Write the diagram as model JSON (below).
2. Wrap it in an envelope: `{"name":"<file name>.ns.svg","model":<model JSON>}`. The name may be in the user's language (`버블정렬.ns.svg`).
3. Make the link: `https://ariadnensd.com/#ns1.u.` + encodeURIComponent(envelope JSON without line breaks).

   If you cannot run code, percent-encode by hand. Encode at least these characters:
   space `%20`, `"` `%22`, `#` `%23`, `%` `%25`, `<` `%3C`, `>` `%3E`, `\` `%5C`, `^` `%5E`, `` ` `` `%60`, `{` `%7B`, `|` `%7C`, `}` `%7D`, `[` `%5B`, `]` `%5D`, `(` `%28`, `)` `%29`. Letters, digits and `-_.!~*':,;=+/?@&$` may stay as they are. Non-ASCII text (Korean, accents) may stay as it is; browsers encode it.
   Make the link last, from the exact JSON you show in the code block, piece by piece. Then check it: the link must have as many `%7B` as `%7D` and as many `%5B` as `%5D`. A missing or extra bracket is the most common reason a link does not open.
4. Give the link as a markdown link, and also show the model JSON in a code block, so the user can fix it if the link is cut.
5. Tell the user, in one or two sentences: the link opens in view mode, Edit makes it editable; after changing it, File › Copy Share Link makes a new link to keep, share, or paste back to you (or another assistant) for more changes; File › Save keeps it as a file.

```json
    { "id": "d1", "head": { "kind": "method", "text": "max(a, n)" }, "body": [ ...blocks... ] }
  ],
  "view": { "folded": [], "opened": [], "bands": true, "resultSymbol": "←" }
}
```

- `settings.textKind`: the language of the text in blocks, for syntax colors only: `plain`, `c`, `cpp`, `java`, `javascript`, `python`, `bash`.
- `settings.theme`: `default`, `dark`, `high-contrast` or `print`.
- `settings.headStyle`: `title` (header drawn as a title) or `shape`.
- `settings.locale`: `en` or `ko`. The language of the words the editor draws ("True"/"False", "default"). Use `ko` when the user writes Korean, otherwise `en`.
- `view`: copy it exactly as above.
- `diagrams[].head` is optional. `{"kind":"method","text":"name(params)"}` for a function, `{"kind":"event","text":"On click"}` for a handler. Leave `head` out for a plain diagram.

## Blocks

A body is an array of blocks, drawn top to bottom.

| Block | JSON |
| --- | --- |
| Process (a statement) | `{"id":"b1","kind":"process","text":"x = 0"}` |
| If | `{"id":"b2","kind":"if","text":"x > 0","yes":{"id":"r1","body":[...]},"no":{"id":"r2","body":[...]}}` |
| Case (switch) | `{"id":"b3","kind":"case","text":"op","arms":[{"id":"r3","label":"'+'","body":[...]}],"otherwise":{"id":"r4","body":[...]}}` |
| While (test first) | `{"id":"b4","kind":"while","text":"i < n","body":[...]}` |
| Do-While (test last) | `{"id":"b5","kind":"doWhile","text":"while swapped","body":[...]}` |
| For | `{"id":"b6","kind":"for","text":"for i = 0 to n - 1","body":[...]}` |
| Call | `{"id":"b7","kind":"call","target":{"kind":"named","name":"swap"},"args":"a[i], a[j]","result":""}` |

- `text` is what is written in the block. Use `\n` for more lines. Write it in the user's language or as code.
- If: both `yes` and `no` are required. A branch may have `"label"` to replace "True"/"False".
- Case: every arm needs `label`. `otherwise` (the default branch) is optional; leave it out if there is none.
- Call: `result` receives the return value (`""` for none), drawn as `result ← name(args)`. To call a Method in the same document, use `"target":{"kind":"local","diagram":"d2"}` where `d2` has a `method` head.

## Rules (a link that breaks one does not open)

1. Ids: diagrams `d1, d2, …`, blocks `b1, b2, …`, branches and arms `r1, r2, …`. A prefix and a whole number from 1, no leading zeros. Every id is used once in the whole document.
2. Every `body` holds at least one block. An empty branch holds an empty process block: `{"id":"b9","kind":"process","text":""}`.
3. Only the keys shown here. No other keys, no comments, no trailing commas.
4. Plain JSON strings: escape `"` and `\` as `\"` and `\\`.

## A link the user gives you

Users paste links made by File › Copy Share Link and ask you to change the diagram. The part after `#` is `ns1.<packing>.<data>`:

| Packing | How to read `<data>` |
| --- | --- |
| `u` | percent-decode it (decodeURIComponent) to the envelope JSON |
| `j` | base64url (RFC 4648 §5, no `=` padding) → UTF-8 envelope JSON |
| `d` | base64url → deflate-raw (RFC 1951, no zlib header) → UTF-8 envelope JSON. Python: `zlib.decompress(base64.urlsafe_b64decode(data + "=" * (-len(data) % 4)), -15)` |

The app's own links are `d` (compressed). If you cannot run code, do not guess what a `d` link holds: say so, and ask the user to attach the saved file (File › Save; the model JSON is plain text inside its `<metadata>`) or to paste the model JSON. Then change the model, keep the ids that stay, give new blocks new ids (the next free number), and give a new `u` link as above.

## If you can run code

Make the same compressed link the app makes: `https://ariadnensd.com/#ns1.d.` + base64url(deflate-raw(UTF-8 envelope JSON)), base64url without `=` padding. In Python: `zlib.compressobj(9, zlib.DEFLATED, -15)` then `.compress(data) + .flush()`; in JavaScript: `new CompressionStream("deflate-raw")`. Check your link by reading it back with the table above.

## A file instead of a link

Very large diagrams (links over about 8,000 characters) are better as a file. Save this as `name.ns.svg`; the user opens it at https://ariadnensd.com/ (Open, or drag the file onto the page):

```xml
<svg xmlns="http://www.w3.org/2000/svg" version="1.1" width="0" height="0" viewBox="0 0 0 0">
  <metadata>
    <ans:document xmlns:ans="https://github.com/reddiana/AriadneNSD" version="1"><![CDATA[
...model JSON...
    ]]></ans:document>
  </metadata>
</svg>
```

The editor draws the picture from the model; saving from the editor writes the full file.
