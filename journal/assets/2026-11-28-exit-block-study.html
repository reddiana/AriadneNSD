M80 · 탈출 블록

탈출(R-BLK-12, 이제 P1)은 반복이나 Method를 중간에 끝내는 블록입니다(break · return · exit). 무한 반복(M79, 정함)에서 나가는 유일한 길이기도 합니다. 이 페이지에서 모양(X1), 글자(X2), 넣는 키(X3, 무한 반복의 키도 함께)를 고릅니다. 각 물음의 1번이 Claude의 추천입니다. 그림의 무한 반복은 M79에서 정한 모양입니다.

참고

DIN 66261의 탈출(Aussprung)

보통 블록의 왼쪽에 꼭짓점이 왼쪽을 향하는 쐐기가 있고, 쐐기 오른쪽에 나가는 곳("Zielort für Aussprung")을 적습니다. 원 논문에는 없고 DIN이 더한 기호입니다. Structorizer의 Jump도 같은 모양입니다.

X1. 탈출의 모양

원칙 2("블록 종류는 색이 없어도 모양만으로 가려진다")를 기준으로 견줍니다. 바탕색은 세 판 모두 처리 블록과 같습니다.

X1 · 1번

DIN 그대로: 왼쪽 쐐기

Claude의 추천
  • NS 차트 표준(DIN 66261)과 Structorizer의 모양입니다.
  • 처리 블록과 모양으로 가려집니다. 쐐기가 "밖으로 나간다"를 가리킵니다.
  • 쐐기 폭(14px)만큼 글자가 오른쪽으로 갑니다.
X1 · 2번

처리 블록에 ↵ 기호

  • 오른쪽 끝에 되돌아가는 화살표를 text.muted로 그립니다.
  • 표준에 없는 표시입니다. 긴 글자가 기호와 겹치지 않게 오른쪽 자리를 비워야 합니다.
X1 · 3번

처리 블록 그대로(지금 스킬이 그리는 방식)

  • 따로 만들 것이 없습니다.
  • 처리 블록과 모양이 같아 원칙 2를 어깁니다. 무한 반복에서 나가는 곳이 눈에 띄지 않습니다.
X2

X2. 탈출 블록의 글자

Claude가 정해 둔 것: 탈출은 반복 · Method 어디에나 넣을 수 있고, 위치를 검사하지 않습니다(NS 차트는 실행기가 아니라 그림이라서). 탈출 뒤의 블록도 그대로 둡니다. continue도 같은 블록에 적습니다.

X2 · 1번

글자 하나를 자유롭게

Claude의 추천
  • 처리 블록처럼 text 하나입니다. break, return 합, break outer, "검색 끝"처럼 무엇이든 적습니다.
  • 코드에서 가져올 때(스킬 · 리버스 엔지니어링) 코드의 말을 그대로 옮깁니다.
  • 새로 넣으면 빈 글자로 열고 바로 적습니다(빈 블록과 같음).
X2 · 2번

종류를 고르고 값을 적음

  • break · return · exit 가운데 고르고(딱지), 뒤에 값을 적습니다.
  • 종류로 검사(반복 밖의 break 알리기)를 할 수 있습니다.
  • 모델이 칸 둘이 됩니다. 딱지의 말을 화면 언어마다 번역할지, Python의 raise처럼 목록에 없는 말은 어디에 둘지 정해야 합니다.
X3

X3. 넣는 키 (무한 반복 · 탈출)

블록 넣기는 a / A + 종류 글자, 감싸기는 s + 종류 글자입니다. 지금 쓰는 종류 글자는 p i w d f k c입니다. 탈출은 처리 블록처럼 감쌀 수 없고(s 없음), 무한 반복은 감쌀 수 있습니다(s + 글자). 그림은 a를 누른 뒤의 키 힌트입니다.

X3 · 1번

무한 반복 e, 탈출 x

Claude의 추천
  • endless, exit의 글자입니다. 영어 이름과 이어져 외우기 쉽습니다.
  • x는 Vim의 "지우기"와 같은 글자지만 a 다음의 둘째 키로만 읽어서 겹치지 않습니다.
X3 · 2번

무한 반복 l, 탈출 b

  • loop, break의 글자입니다.
  • l은 While · For와 같은 "반복"이라 어느 반복인지 흐립니다. b는 return · exit와 이어지지 않습니다.
X1 · 1번 · 겹침

Method 안에서(1번 · 1번)

무한 반복 안의 break와, Method를 끝내는 return입니다.

답하실 것

  1. X1, X2, X3 하나씩, 번호 또는 고칠 점.
  2. 병렬 처리(M81)와 주석(M82)의 시안도 이어서 있습니다. 넣는 키는 세 시안을 겹치지 않게 골랐습니다.
