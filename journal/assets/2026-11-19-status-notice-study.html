M64 상태 표시줄 알림의 색

2026-11-19 · 시각 디자인 문서 11장의 어긋남 4/7. 그림은 실제 앱의 상태 표시줄입니다. info 알림 "선택한 것을 풀었습니다. 이동 키를 누르면 마지막에 선택했던 블록부터 다시 선택합니다."는 블록을 선택한 채 Esc를 눌러 띄웠고, 2번의 색은 앱 코드를 바꾸지 않고 입혀 찍었습니다.

움직임은 두지 않습니다. 예외 하나: 상태 표시줄의 알림 텍스트가 1.6초 동안 ui.accent로 보였다가 돌아옵니다. (시각 디자인 9.4절)

NT1 알림이 나타날 때 색을 잠깐 바꿀까

지금 앱은 색을 바꾸지 않습니다. info 알림은 6초 뒤 사라지고, warn 알림은 닫거나 다음 알림이 올 때까지 남습니다. 버튼을 누르면 실제 시간으로 재생합니다.

9.4절의 "움직임은 두지 않습니다"에 예외가 없어집니다. 명세의 예외 문장을 지웁니다.

21.6초 동안 강조색으로 표시

새 알림이 눈에 더 잘 띕니다. 키보드로 빠르게 작업할 때 알림이 잦으면 상태 표시줄이 자주 깜박입니다.
