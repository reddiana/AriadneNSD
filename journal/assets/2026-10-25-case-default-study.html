M37 · default 없는 Case

편집기로 만드는 Case에는 늘 default가 있습니다. 그런데 코드에서 가져온 switch는 default가 없거나 default만 있을 수 있습니다(모델은 둘 다 담음). 이것을 어떻게 그릴지 고릅니다. 프로토타입에는 이런 Case가 없어 "참고"로 보통 Case를 그렸습니다. 각 물음의 1번이 Claude의 추천입니다.

비교용

C1. default가 없는 Case

Claude의 추천
  • NS 차트 표준에서 default가 없을 때의 그림입니다. 짧은 빗금이 없어 "default 없음"이 모양으로 보입니다.
  • 보통 Case의 규칙(긴 빗금은 default 칸의 왼쪽 아래로)에서 default 칸이 없을 뿐이라, 따로 규칙이 늘지 않습니다.
C1 · 2번

빈 default 칸을 그려 둠

  • 보통 Case와 모양이 같습니다. 코드의 뜻도 같습니다(default가 없으면 아무 일도 하지 않음).
  • 모델에 없는 갈래가 그림에 보입니다. 그 칸을 고르거나 글자를 적으면 어떻게 되는지 따로 정해야 합니다.

C2. default만 있는 Case

결정함 (2026-10-25): 1번 짧은 빗금 하나.

C2 · 1번

짧은 빗금 하나 (오른쪽 위에서 왼쪽 아래로)

Claude의 추천
  • 같은 규칙에서 나옵니다: default 칸이 블록 전체이니, 긴 빗금은 길이가 없고 짧은 빗금만 남습니다.
  • If의 머리와 다른 모양이라 헷갈리지 않습니다.
C2 · 2번

빗금 없이 머리와 default 이름만

  • 가장 단순합니다.
  • 빗금이 없어 Case인지 알아보기 어렵습니다. 처리 블록 둘이 쌓인 것처럼 보입니다.
