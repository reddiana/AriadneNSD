Q2. 접힌 칸을 더블클릭하면

"입력 검사"라는 접힌 칸이 있습니다. 블록에서는 더블클릭이 글자 고치기입니다. 접힌 칸에서도 고치기로 맞출지, 지금처럼 펼치기로 둘지를 고릅니다.

Q2 · 1번

더블클릭은 어디서나 고치기. 접고 펴기는 세모로

추천
  • 더블클릭하면 이름을 고칩니다(블록과 같음).
  • 펴려면 칸 왼쪽의 세모(▸)를 한 번 누르거나 접기 · 펴기 명령을 씁니다.
  • 이름 띠도 같습니다: 더블클릭은 이름 고치기, 세모(▾)는 접기.
Q2 · 2번

접힌 것에서는 더블클릭이 펼치기

지금
  • 더블클릭하면 펼쳐집니다. 이름은 Enter나 F2로 고칩니다.
  • "더블클릭 = Enter"가 접힌 칸과 이름 띠에서는 맞지 않습니다.

Q3. 새로 만든 것의 이름을 적다가 Esc를 누르면

Q6. 순서 바꾸기를 명령 하나로

Q7. 푸는 명령을 하나로

Q9. 실행 취소가 되돌리는 것

정해진 것

접고 펴기는 되돌리지 않는다

글자를 "1보다"로 고치고, 접고, 실행 취소를 했습니다. 접힌 것은 그대로이고 글자만 "0보다"로 돌아갑니다.

  • 반복문을 접으려면 반복문을 골라야 합니다.

Q21. 부르는 곳이 있는 Method를 Event로 바꾸면

왼쪽 다이어그램이 Method reset을 부르고 있습니다. reset의 머리를 고르고 Event로 바꾸려 합니다. Event는 부를 수 없습니다. 같은 Method의 머리를 떼거나 다이어그램을 지우는 것은 지금도 허용하고, 호출 블록에 "?"가 붙습니다.

Q21 · 1번

바꾸게 둔다. 호출 블록에 "?"

추천
  • 머리 떼기 · 다이어그램 지우기와 같은 결과가 됩니다.
  • 편집기에 "막는 자리"가 하나 줄어듭니다. 실행 취소로 되돌릴 수 있습니다.
Q21 · 2번

막는다

지금 · 어제 확인하신 것
  • Event로 바꾸기만 막고, 머리 떼기와 지우기는 허용합니다.
  • 호출 블록이 끊기는 일을 하나 줄입니다.

Q22. 우선순위 태그와 MVP 범위

"#P0 = MVP 필수"이고 MVP의 배포 대상은 웹뿐인데, Obsidian 항목 일곱 개와 데스크톱의 파일 열기가 #P0입니다. 태그의 뜻을 바꿀지, 태그를 내릴지를 고릅니다.

Q22 · 1번

태그는 기능의 우선순위만. 배포 순서는 ADR-0011

추천
항목태그읽는 법
웹: 로컬 파일 열기#P0MVP에 들어감 (웹이 첫 대상)
Obsidian: Insert new NS diagram#P0Obsidian 판을 낼 때 필수. MVP는 아님
데스크톱: 파일 열기 · 저장#P0데스크톱 판을 낼 때 필수. MVP는 아님

태그는 그대로 두고 "읽는 법"에 한 줄을 더합니다.

Q22 · 2번

Obsidian과 데스크톱의 #P0을 #P1로 내린다

항목태그읽는 법
웹: 로컬 파일 열기#P0MVP
Obsidian: Insert new NS diagram#P0 → #P11차 확장
데스크톱: 파일 열기 · 저장#P0 → #P11차 확장

"#P0 = MVP"가 글자 그대로 맞게 됩니다. Obsidian 안에서 무엇이 필수이고 무엇이 나중인지는 가를 수 없게 됩니다.

Q23. "머리"와 "선택 블록"

요구사항에서 ①과 ②를 둘 다 "머리"라고 부릅니다. 또 "선택 블록"이 용어집에서는 If 블록이고, 요구사항 여러 곳에서는 "고른 블록"입니다.

Q23 · 1번

낱말을 나눈다

추천
  • ① 머리: 다이어그램의 Event · Method 머리만.
  • ② 조건 칸: 제어 블록의 조건이 적힌 윗부분.
  • ③ If 블록이라고만 부르고, 고른 것은 고른 블록이라고 적습니다. "선택 블록"은 쓰지 않습니다.
Q23 · 2번

그대로 둔다

지금
  • ①과 ②가 둘 다 머리.
  • ③은 선택 블록. "선택 블록의 앞에 넣는다"가 If 블록인지 고른 블록인지 글만으로는 알 수 없습니다.
