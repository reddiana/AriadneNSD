5분 둘러보기

배열의 합과 평균을 구하는 NS 차트를 처음부터 그려 봅니다. 키보드만으로도, 마우스만으로도 됩니다. 키는 왼쪽이 Vim 키, 오른쪽이 표준 키와 마우스입니다. 둘 중 손에 익은 쪽을 쓰면 됩니다.

앱을 열면 빈 블록 하나가 선택된 새 문서가 보입니다. 위에는 메뉴와 툴바가, 아래에는 지금 선택한 것을 알려 주는 상태 표시줄이 있습니다.

1첫 블록 적기

선택한 블록에 글자를 적으려면 편집을 시작합니다. 적고 나서 Enter를 누르면 받아들입니다. Esc도 적은 대로 받아들입니다.

→
하는 일 Vim 키 표준 키 · 마우스
편집 시작 i (글자 앞에 커서), cc (비우고 새로) Enter, F2, 더블클릭
받아들이기 Esc Enter
블록 안에서 줄 바꾸기 Shift+Enter

블록이 선택된 채로 글자 키를 누르면 글자가 적히지 않고 명령이 됩니다(Vim과 같습니다). 적으려면 먼저 편집을 시작하세요.

2블록 더 넣기

새 블록은 선택한 블록의 뒤에 들어갑니다. 처리 블록을 넣으면 바로 편집이 시작되니, 적고 Enter, 다시 넣고 적기를 되풀이합니다. 앞에 넣으려면 Shift를 함께 누릅니다.

→
하는 일 Vim 키 표준 키 · 마우스
처리 블록을 뒤 / 앞에 넣고 바로 적기 o / O 툴바의 처리 블록 아이콘 / Shift+클릭
블록 사이를 오가기 j k ↓ ↑, 클릭

3While로 감싸기

아래 두 블록 sum ← sum + a[i]와 i ← i + 1을 반복문 안에 넣습니다.

  1. 두 블록을 함께 선택합니다. 방금 적은 i ← i + 1이 선택된 채로 Shift+↑를 한 번 누르면 바로 위 블록까지 선택되어, 주황 테두리가 두 블록을 함께 감쌉니다. 마우스로는 sum ← sum + a[i]를 클릭한 뒤 i ← i + 1을 Shift+클릭합니다.
  2. While로 감쌉니다. s를 누르고 w를 누릅니다. 마우스로는 툴바의 While 아이콘을 Ctrl+클릭합니다.
  3. 반복 조건을 적습니다. 편집이 바로 시작되니 i < n을 적고 Enter를 누릅니다.
→ →

아래는 같은 과정을 화면 전체로 보인 것입니다. s를 누르고 잠깐 기다리면 선택한 블록 바로 아래에 다음에 누를 키의 힌트가 뜹니다.

하는 일 Vim 키 표준 키 · 마우스
여러 블록 선택 V 다음 j k Shift+↑ ↓, Shift+클릭
While로 감싸기 s w 툴바의 While 아이콘을 Ctrl+클릭, 툴바의 "감싸기", 아이콘을 블록 위에 끌어 놓기
다른 종류로 감싸기 s + i If · k Case · d Do-While · f For 같은 방법으로 그 아이콘
감싼 것 풀기 ds 컨텍스트 메뉴(오른쪽 클릭)

두 글자 명령은 첫 키를 누르고 잠깐 기다리면 선택한 블록 바로 아래에 다음에 누를 수 있는 키가 보입니다. 외우지 않아도 됩니다.

5저장하기

저장하면 .ns.svg 파일이 생깁니다. 이 파일은 그 자체로 그림이라 브라우저, GitHub, 문서에 그대로 보이고, AriadneNSD로 다시 열면 이어서 고칠 수 있습니다.

오른쪽 위의 파일 이름 옆 점(●)은 아직 저장하지 않았다는 뜻입니다.

하는 일 Vim 키 표준 키 · 마우스
저장 / 다른 이름으로 저장 Ctrl+S / Ctrl+Shift+S, 툴바의 저장 아이콘
실행 취소 / 다시 하기 u / U Ctrl+Z / Ctrl+Y
모든 키 보기 ? 도움말 › 단축키 목록

Chrome과 Edge에서는 한 번 저장한 파일을 그 뒤로 자동으로 저장합니다. Firefox와 Safari에서는 저장할 때마다 파일을 내려받습니다. 저장하지 않은 내용도 브라우저에 임시로 보관되어, 페이지를 다시 열면 복원할지 묻습니다.

화면

  • 메뉴 바: 파일 · 편집 · 다이어그램 · 보기 · 도움말. 모든 명령이 여기에 있고, 키가 있으면 옆에 보입니다.
  • 툴바: 새로 · 열기 · 저장 · 내보내기, 실행 취소 · 다시 하기, 잘라내기 · 복사 · 붙여넣기, 블록 아이콘 다섯(처리 · If · Case · While · Do-While), 감싸기, 확대 · 축소, 예제.
  • 캔버스: 다이어그램을 그리는 곳. 다이어그램이 여럿이면 자동으로 늘어놓습니다.
  • 상태 표시줄: 지금 선택한 것과 알림. 오른쪽 위의 파일 이름 옆 ●는 저장하지 않았다는 뜻입니다.

블록

블록 안의 글은 자유롭게 적습니다. 코드든 문장이든 됩니다. 글은 자동으로 줄을 바꾸지 않으니, 길면 Shift+Enter로 나눕니다. 빈 칸의 ∅는 "여기는 비어 있음"이라는 표시입니다.

블록 뜻 종류 글자
처리 한 단계의 일 (o O로 넣음)
If 조건에 따라 참 · 거짓 두 분기 i
Case 값에 따라 여러 분기, 맨 끝은 default k
While 조건을 먼저 보고 반복 w
For 정해진 횟수만큼 반복(모양은 While과 같고 글로 구분). 툴바에는 없고 키와 메뉴로 넣음 f
Do-While 한 번 하고 나서 조건을 보고 반복 d
호출 같은 문서의 Method를 부름 c

종류 글자는 넣기(a A)와 감싸기(s) 뒤에 이어 누르는 글자입니다.

감싸기 · 풀기, 분기 더하기

감싸기는 선택한 블록들을 새 제어 블록 안에 넣습니다(If는 참 분기, Case는 첫 분기에). 풀기는 반대로 껍데기만 없애고 안의 블록을 남깁니다. Case의 분기는 분기 라벨을 선택하고 블록처럼 넣고 지웁니다. default는 늘 맨 끝입니다.

Event · Method와 여러 다이어그램

한 문서에 다이어그램을 여럿 둘 수 있습니다. 헤더를 달면 다이어그램이 Event(인터럽트, 타이머처럼 밖에서 시작되는 것)나 Method(호출 블록으로 부르는 것)가 됩니다. 늘어놓는 것은 자동이어서 Event는 왼쪽, Method는 오른쪽에 모입니다. 호출 블록의 이름은 Method의 헤더를 따라가고, 블록마다 인자와 결과만 적습니다.

파일

AriadneNSD는 서버 없이 브라우저에서만 돕니다. 파일은 내 컴퓨터에 그대로 남습니다. 저장한 .ns.svg는 그 자체로 그림이라 어디서든 보이고, 같은 파일을 다시 열면 이어서 고칠 수 있습니다.

  • 열기: 파일 메뉴, 툴바, 또는 파일을 페이지 위에 끌어 놓기. .ns.svg와 .ns를 엽니다.
  • 저장: Ctrl+S, 다른 이름으로 저장은 Ctrl+Shift+S. Chrome · Edge는 원래 파일에 쓰고, 한 번 저장한 뒤로는 자동으로 저장합니다. Firefox · Safari는 저장할 때마다 내려받습니다.
  • 최근 파일: 파일 메뉴에서 열거나 저장한 파일을 열 개까지 다시 엽니다.
  • 임시 보관: 저장하지 않은 내용도 브라우저에 남아, 페이지를 다시 열면 복원할지 묻습니다.
  • PNG로 내보내기: 파일 › 내보내기. 저장하는 그림과 같은 모습입니다.
  • 예제: 툴바의 "예제"나 도움말 › 예제…에서 열 가지를 엽니다. 예제는 새 문서로 열리므로 고쳐도 됩니다.

AriadneNSD는 아직 1.0 전입니다. 지금 저장한 파일은 뒤의 버전에서 열리지 않을 수 있습니다.

문제 알리기

이상하게 움직이거나 그림이 틀리면 알려 주세요. 무엇을 했고(누른 키, 클릭한 곳), 무엇을 기대했고, 무엇이 일어났는지를 적어 주시면 고치기가 쉽습니다. 도움말 › AriadneNSD에 대하여의 버전과 브라우저 · OS도 함께 적어 주세요.

  • 공개로: GitHub 이슈. 다른 사람도 보고 함께 확인할 수 있습니다.
  • 비공개로: 다이어그램을 공개하고 싶지 않으면 report@ariadnensd.com으로 메일을 보내 주세요. .ns.svg 파일은 원할 때만 첨부하면 됩니다.
