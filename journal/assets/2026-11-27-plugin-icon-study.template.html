M78 플러그인 아이콘

Anthropic Directory에 제출할 플러그인 ariadne-nsd의 아이콘을 고릅니다. 네 안 모두 지금 쓰는 로고(DR-0006)의 SVG를 그대로 쓰고, NS 차트 배지만 새로 그렸습니다. 크기마다 실제 픽셀로 보입니다.

  • 아이콘은 처음 제출할 때 한 번만 정해지고, 나중에 파일을 바꿔도 목록의 아이콘은 그대로입니다.
  • 형식은 정사각형 PNG 512~2048px(SVG 불가)입니다. 고른 안을 1024px PNG로 뽑아 .claude-plugin/icon.png에 둡니다.
  • 목록에서는 대개 32~48px로, 상세 화면에서는 더 크게 보입니다. 그래서 작은 크기에서 알아보이는지가 중요합니다.
지금 쓰는 곳: 앱 정보 창 = I1의 큰 판, 사이트 탭 아이콘 = I2의 작은 판. 아래 "목록 줄"은 실제 Directory 화면이 아니라 크기를 가늠하려고 그린 줄입니다.
