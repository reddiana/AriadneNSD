링크를 보내 주셔서 감사합니다. 그런데 이 링크는 `#ns1.d.`로 시작하는 압축(`d`) 링크입니다. 다이어그램이 deflate로 압축된 뒤 base64url로 인코딩되어 있어서, 코드를 실행할 수 없는 지금의 저는 내용을 정확히 풀어 읽을 수 없습니다. 추측해서 고치면 버블 정렬의 기존 블록이 틀어질 수 있으니, 짐작으로 만들지 않겠습니다.

아래 둘 중 하나로 알려 주세요.

1. **저장한 파일을 붙여 주세요.** AriadneNSD에서 파일 › 저장(File › Save)으로 만든 `.ns.svg` 파일을 첨부해 주세요. 파일 안의 `<metadata>`에 모델 JSON이 일반 글자로 들어 있습니다.
2. **모델 JSON을 붙여 주세요.** 파일을 열 수 없다면 `<metadata>` 안의 JSON 글자를 복사해서 붙여 주셔도 됩니다.

받으면 다음과 같이 고치겠습니다.

- 바깥 반복(한 바퀴)을 시작하기 전에 `swapped = false`를 두고, 안쪽 비교에서 자리를 바꿀 때 `swapped = true`로 바꿉니다.
- 바깥 반복을 "한 바퀴 동안 바꾼 것이 없으면 끝" 조건(`while swapped`인 Do-While 등)으로 바꿔 일찍 끝나게 합니다.
- 기존 블록의 id는 그대로 두고, 새 블록에는 다음 빈 번호를 붙입니다.
- 고친 결과를 새 공유 링크와 모델 JSON 코드 블록으로 함께 드립니다.

참고로, 새 링크는 열면 보기 모드로 열리고 편집하기 버튼을 누르면 고칠 수 있습니다.
