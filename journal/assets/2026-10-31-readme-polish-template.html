M42 README 첫 화면 다듬기

펴낸 사이트의 첫 화면에서 (가) 예제 그림의 하얀 바탕, (나) 프로토타입 링크가 눈에 안 띄는 것을 고칩니다. 장면은 사이트의 색 그대로입니다. 테마를 바꿔 보세요.

(가) 예제 그림의 바탕

그림은 바탕이 흰 PNG입니다. 프로토타입이 흰 종이 위에 그리므로, 그림 자체는 그대로 두고 둘레만 바꿉니다.

가2 종이 카드 추천

흰 바탕에 여백·옅은 테두리·둥근 모서리·그림자를 주어 "종이 한 장"으로 보이게 합니다. 두 테마 모두 일부러 둔 흰색으로 읽힙니다. NS 차트의 색은 그대로입니다.

가3 밝은 테마는 녹이고, 어두운 테마는 카드

{{IMGS}}

밝은 테마에서는 흰색이 페이지 바탕색이 되어 그림이 페이지에 바로 그려진 듯 보입니다. 어두운 테마에서는 녹일 수 없어(차트 색이 뒤집힘) 카드로 둡니다. 두 테마의 모습이 달라집니다.

사이트에서만 듣는 꾸밈입니다(site/custom.scss). GitHub의 README는 꾸밈을 지우므로 그대로 보이는데, GitHub의 밝은 화면은 바탕이 흰색이라 문제가 적습니다.
