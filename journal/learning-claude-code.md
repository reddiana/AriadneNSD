# Claude Code 초보자의 배움 기록

이 프로젝트는 **Claude Code를 처음 쓰는 사람**이 Claude와 함께 프로그램을 만들어 가는 과정이기도 합니다.
NS 차트 편집기를 만드는 이야기와 함께, "AI와 일하는 법을 배워 가는 이야기"를 여기에 모읍니다. 영상에서 별도 챕터로 쓸 수 있습니다.

## 2026-10-07 — 첫날 배운 것

| # | 배운 것 | 그 순간 |
| --- | --- | --- |
| 1 | **질문으로 시작해도 된다.** 웹 검색으로 자료를 찾아 준다. | "NS Chart를 설명한 사이트를 추천해주세요" |

| 10 | **문서 구조나 일하는 방식 자체도 같이 설계할 수 있다.** | 요구사항 / ADR / 설계 / 협업 기록 / 여정 기록으로 폴더를 나눔 |

### Claude Code의 동작 방식

| # | 배운 것 | 그 순간 |
| --- | --- | --- |
| 11 | **git 커밋도 부탁할 수 있다.** 커밋 메시지도 Claude가 쓴다. | "오늘은 여기까지 하겠습니다. git commit도 해주세요." |
| 12 | **Claude를 종료하면 대화 내용을 기억하지 못한다.** 자동 요약도 없다. | "클로드를 종료하고 다시 시작하면 recap 내용을 다시 알려주나요?" |

| 14 | **`CLAUDE.md`는 Claude가 매번 자동으로 읽는 프로젝트 안내 파일이다.** 여기에 규칙을 적어 두면 새 세션에서도 지킨다. | "세션 시작 시 지난 작업 요약" 규칙을 넣음 |
| 15 | **기억은 파일로 남긴다.** 세션 기록과 현재 상태(`plan/`)를 남겨 두면 새 세션에서도 이어갈 수 있다. | `plan/` 폴더(처음 이름은 `collab/`)를 만든 이유 |
