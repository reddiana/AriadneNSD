# 결정 기록

(← [[atelier/README|작업 공간]])

아키텍처는 아니지만 까닭을 남겨 둘 결정입니다: 일하는 순서, 조작과 모습, 이름 · 로고 · 라이선스. 형식과 상태, "이후 변경"을 다는 법은 ADR과 같습니다. 파일은 `decisions/`에 있고 이름은 `dr-NNNN-…`입니다. 조작과 화면의 작은 결정은 DR 파일 대신 같은 폴더의 [[ux-decisions|UX 결정 모음]]에 한 항목씩 있습니다(2026-10-18 → DR-0012). DR-0002~0011은 2026-10-17에 ADR에서 옮겨 온 것이고, 옛 번호는 아래 표와 각 기록의 "이후 변경"에 있습니다.
