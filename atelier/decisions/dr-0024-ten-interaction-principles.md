# DR-0024: 조작의 원칙을 열 개로 다시 묶는다

## 배경

메인테이너(2026-11-28): "이번을 포함해서 그동안 interaction-rules을 많이 추가하고 고쳤습니다. 일관성이 떨어질 것이 걱정됩니다. UX엑스퍼트로서 점검해주세요. UX엑스퍼트는 큰 원칙들로 정리할 수 있을 것 같아요."

조작 규칙([[02-interaction-rules]])과 [[ux-decisions|UX 결정]]을 한 줄씩 [[01-ux-overview#2. UX 원칙|UX 원칙]] 일곱에 이어 보니, 어느 원칙에도 이어지지 않으면서 이미 여러 번 같은 쪽으로 정해 온 생각이 일곱 묶음(A ~ G) 있었다. 원칙 "뷰 상태와 내용을 구분한다"는 [[ux-decisions#UN1. 접고 펴기도 실행 취소의 대상|UN1]](접고 펴기도 실행 취소 대상) 뒤로 문장이 규칙과 맞지 않았다. 점검과 비교한 안은 시안 M87(https://claude.ai/artifact/KGGZjKgapKTnDW6aXruM5J, 사본 `journal/assets/2026-11-28-ux-principles-audit.html`)에 있다.

| 후보 | 한 줄 | 이 생각으로 이미 정한 규칙 |
| --- | --- | --- |
| A | 보이는 상자 하나가 조작의 한 단위 | MD1, FD5, 이동, DF1(M86), CB5, NF1, Q10, BI1 |
| B | 선택한 것이 대상, 아니면 가장 가까운 담은 것 | Q8, FD1, FD6, 풀기, XM3 |
| C | 말과 차례는 그림의 방향 | Q5, NM1, MO1 |
| D | 명령 뒤에는 바뀐 것을 선택하고 바로 적게 한다 | Q19, FD4, FD7, FD10, XM2, CB15, OP1 |
| E | 되돌릴 수 있으면 묻지 않는다 | 다이어그램 삭제, 새 Method로 빼기, US1, BS3 |
| F | 받아들이기는 넓게, 만들기는 좁게 | MD3의 "모델은 넓게", CD1 · CD2, ADR-0052, DC1, XB1 |
| G | 미리 보이고, 한 뒤에 알린다 | DI1, K3, W2, Q8, DD1 |

## 결정 기준

- 규칙을 하나 더할 때 어느 원칙을 따르는지 바로 말할 수 있어야 한다.
- 외울 수 있는 수여야 한다. 원칙이 열을 넘으면 절마다 다는 원칙도 길어진다.
- 공통 규칙(R1 ~ R7)은 "같은 종류의 일을 한 규칙으로"이고, A ~ G는 판단의 기준이라 원칙 쪽에 둔다.

## 검토한 대안

### 대안 A: 큰 원칙 열 개로 다시 묶기

- 장점: 비슷한 후보를 묶어(A + C, B + D, 원칙 + E, 원칙 + G) 수가 적다.
- 단점: 원칙 하나가 두 가지를 말하는 곳이 있다.

### 대안 B: 지금 일곱 + 새 일곱 = 열넷

- 장점: 하나하나가 뚜렷하다.
- 단점: 원칙이 많다.

### 대안 C: 원칙은 그대로, 후보는 공통 규칙 R8 ~ R14로

- 장점: 원칙 표를 건드리지 않는다.
- 단점: 일의 종류가 아닌 판단 기준이 공통 규칙에 섞인다.

## 결정

**대안 A (메인테이너, 2026-11-28, M87의 Q1 1번).** 원칙은 아래 열 개다. 본문은 [[01-ux-overview#2. UX 원칙]].

1. 구조를 편집하면 그림이 따라온다 (그대로)
2. 보이는 대로 다룬다 (새: A + C)
3. 선택한 것이 대상이다 (새: B + D)
4. 같은 일은 같은 방법으로 (고침: 명령 하나, 입구 여럿 → [[0033-command-list-for-shells|ADR-0033]])
5. 키보드만으로 모두 (그대로)
6. Vim의 손에 맞게 (그대로)
7. 실행 취소 한 번으로 돌아온다 (고침: "뷰 상태와 내용을 구분한다" + E)
8. 막지 않고 알린다 (고침: + G)
9. 받아들이기는 넓게, 만들기는 좁게 (새: F)
10. 화면은 다이어그램에게 (그대로)

같은 시안에서 원칙에 비추어 어긋난 곳도 정했다: F2 ~ F8 → [[ux-decisions#22. 2026-11-28의 결정]]의 DF2 · DF3 · HD1 · AR2 · MD4 · BL1 · TW1. 원칙 7은 F6(If ↔ Case를 묻지 않음)으로 예외 없이 "되돌릴 수 없을 때만 묻는다"가 되었다.

## 결과

- 좋아지는 점: 조작 규칙의 절마다 첫머리에 따르는 원칙을 단다. 새 규칙은 원칙을 먼저 대 보고 정한다.
- 감수하는 점: 원칙 2 · 3은 두 생각을 묶어 문장이 길다.
- 후속 작업: 없음(F2 ~ F7의 구현은 2026-11-28 에이전트).
