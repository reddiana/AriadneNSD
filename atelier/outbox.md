# Outbox

> [!abstract] 이 문서는
> Claude가 메인테이너에게 보내는 것, 곧 **메인테이너의 답을 기다리는 것**만 모은 목록입니다. [[inbox]](메인테이너 → Claude)와 짝입니다. 2026-10-22까지 이름은 `debt`(부채 목록)였습니다. Claude는 세션을 시작할 때 "정해 주세요"와 "확인해 주세요"를 보여 줍니다.
> - **정해 주세요:** 메인테이너가 정해야 다음으로 갈 수 있는 것
> - **확인해 주세요:** Claude가 정해 놓고 확인받지 못한 것. "그대로"라고만 하셔도 됩니다
> - **알아만 두세요:** 답이 필요 없는 보고 가운데 다른 문서에 둘 자리가 없는 것
> - 두 절 모두 **주제별로** 묶습니다: 요구사항 · 범위, 모델 · 파일 형식, 조작 · 키, 시각 디자인, 아키텍처 · 기술, 문서 · 저장소 · 일하는 방식, 이름 · 로고 · 라이선스(2026-10-17, 메인테이너 inbox). 같은 날 함께 정한 묶음이 여러 주제에 걸치면 주제마다 나누고, 묶음의 이름과 날짜를 그대로 붙입니다.
> - 미뤄 둔 일은 여기가 아니라 [[backlog]]에, 프로토타입의 알려진 구멍과 시험하지 못한 곳은 [[prototype]]에, 로고와 이름에 대한 보고는 [[logo-source#남은 확인]]과 [[names-and-registries]]에 있습니다.
> - 답을 받은 항목은 체크하고 어디에 반영했는지 링크를 남깁니다. 체크한 항목은 마무리 때 세션 기록으로 옮기고 지웁니다(2026-10-12 이전에 처리한 것은 세션 기록과 git에 있습니다).

- [ ] MVP에 헤더 · 호출 블록을 넣으며 Claude(에이전트)가 정한 것 (2026-11-01 → [[2026-11-01-02-docs-current-examples]]). 설계 문서에 반영함
	- 키: `e` `m`(선택에 따라 헤더 달기 · 종류 바꾸기), `E` `M`(새 Event · Method 다이어그램), `a c` · `A c`(호출 블록 넣기 → Method 목록), 헤더에서 `x` `dd` `Delete`는 헤더 제거, `Shift`+`Delete`는 다이어그램 삭제(묻지 않고 지우고 "실행 취소로 되돌릴 수 있습니다"를 알림, 다이어그램 안 어디서나), 헤더에서 `Alt`+방향키는 다이어그램 순서
	- 헤더 없는 다이어그램에서는 블록을 선택했어도 `e` `m`이 헤더 달기. 헤더가 있는 다이어그램의 블록에서 `m`은 "새 Method로 빼기는 아직 지원하지 않습니다"를 알림
	- 헤더에서 `↑`는 움직이지 않음, `Ctrl`+`↓`는 첫 블록, `gg`는 헤더. 옆 다이어그램은 그려진 순서(Event · 헤더 없는 것 먼저, 그다음 Method)
	- "새 Method를 만들고 호출"은 Method 목록의 끝, 고르면 새 Method의 이름 편집이 열림. 호출 블록의 빈 칸에 "인자" · "결과"가 흐리게 보임. 헤더 위에는 끌어 놓을 수 없음
	- "제목처럼" 헤더의 선택 테두리는 헤더 바깥으로 4px 넓힘(글자가 왼쪽 선에 붙어 있어 덮지 않게)
	- 사용자가 마지막에 고른 헤더 모양은 사용자 설정 `editor.headStyle`. 예제도 이 모양으로 열림. 첫 방문 여부는 `examples.welcomed`
	- 썸네일 비율 16 : 9(4 : 3이면 노트북 화면에서 셋째 줄이 잘림)
	- 맨 아래에서 `↓`로 담은 블록을 선택한 뒤, 거기서 `↓`를 또 누르면 다시 안으로 들어가 둘을 오감([[ux-decisions#ND1. 맨 아래에서 아래로|ND1]]. 담은 블록을 선택하는 것은 메인테이너가 확인함)
- [ ] MVP 개발에서 Claude(에이전트)가 정한 것 가운데 사용자에게 보이는 것 (2026-11-01 → [[2026-11-01-01-confirmations-terms-mvp]]). 설계 문서에 반영함
	- 열기에는 단축키가 없음(`Ctrl`+`O`는 브라우저와 겹침). 줌 키는 `+` `-`만(브라우저 줌 `Ctrl`+`=`를 가로채지 않음), `Ctrl`+휠은 마우스 자리를 중심으로
	- Chromium에서 방금 연 파일은 읽기 권한만 있어, 자동 저장은 한 번 저장(`Ctrl`+`S`)한 뒤부터
	- 저장 성공은 알리지 않음(자동 저장 때문). 실패와 "다른 이름으로 저장" 성공만 알림. 알림은 상태 표시줄 하나(info 6초, warn은 닫을 때까지)
	- 실행 취소 500단계, `Backspace`도 삭제, 인라인 편집 중에도 `Ctrl`+`S` · `Ctrl`+`Shift`+`P` · `F1`이 들음
	- 저장 파일의 고정 문구(If의 "참" · "거짓")는 저장할 때의 화면 언어를 따름(조작 규칙대로). 그래서 한국어로 저장한 파일을 영어 화면에서 다시 저장하면 바이트가 달라짐. 이대로 둘지
	- 웹 첫 내려받기의 번들 사이즈 체크(bundle size budget) 한도 540 KB(gzip, 지금 450 KB). 넘으면 CI가 실패
	- 새 Case의 분기 라벨은 `1` · `2` · default, 새 분기는 쓰이지 않은 가장 작은 정수
