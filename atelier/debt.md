# 부채 목록

> [!abstract] 이 문서는
> **메인테이너의 답을 기다리는 것**만 모은 목록입니다. Claude는 세션을 시작할 때 "정해 주세요"와 "확인해 주세요"를 보여 줍니다.
> - **정해 주세요:** 메인테이너가 정해야 다음으로 갈 수 있는 것
> - **확인해 주세요:** Claude가 정해 놓고 확인받지 못한 것. "그대로"라고만 하셔도 됩니다
> - **알아만 두세요:** 답이 필요 없는 보고 가운데 다른 문서에 둘 자리가 없는 것
> - 미뤄 둔 일은 여기가 아니라 [[backlog]]에, 프로토타입의 알려진 구멍과 시험하지 못한 곳은 [[prototype]]에, 로고와 이름에 대한 보고는 [[logo-source#남은 확인]]과 [[names-and-registries]]에 있습니다.
> - 답을 받은 항목은 체크하고 어디에 반영했는지 링크를 남깁니다. 체크한 항목은 마무리 때 세션 기록으로 옮기고 지웁니다(2026-10-12 이전에 처리한 것은 세션 기록과 git에 있습니다).

## 확인해 주세요

- [ ] 요구사항과 설계를 나누며 Claude가 정한 것. 확인받지 못함 (2026-10-12)
	- "분석 또는 설계" 가운데 **설계**로 봄. 분석 문서를 따로 만들지 않고 UX 설계 폴더에 [[01-interaction-rules]](모습과 조작 규칙)를 새로 둠. 파일 이름과 제목은 Claude가 붙임
	- 나누는 금: 요구사항에는 체크박스 한 줄(블록 ID가 붙은 문장)과 표를 남기고, 그 아래 달려 있던 세부 규칙과 "여러 블록 선택 규칙" · "감싸기 · 풀기" · "접기 · 펼치기"의 본문을 옮김. 세 제목은 링크가 끊기지 않게 요구사항에 한두 문장으로 남김
	- 문장은 고치지 않고 그대로 옮김(같은 문서를 가리키던 링크만 고침). 그래서 [[requirements-review]]가 짚은 모순과 빠진 곳, 문장 속의 키는 그대로 있음
	- 옮기지 않은 것: 2장 배포 대상의 세부(후원 링크의 자리, 웹의 파일 열기 · 공유 URL · 광고, Confluence의 Forge 설명), 3.3~3.6, 4장. 모양 설명("낮은 아치 모양", "양옆 세로 이중선", "모자 모양", 표의 "역삼각형 헤더" 등)은 메인테이너의 말("모양 설명은 옮겨주세요")로 [[01-interaction-rules#블록의 모양]]에 옮김. 표의 설명 칸에 모양 대신 적은 뜻("조건에 따라 참 갈래나 거짓 갈래를 실행" 등 세 줄)은 Claude가 씀
	- 요구사항의 세부를 가리키던 승인 ADR들(예: `[[01-requirements#접기 · 펼치기]]`)에는 "이후 변경"을 달지 않음. 링크는 요구사항의 짧은 절에 닿고 거기서 설계 문서로 이어짐
	- 여러 다이어그램의 배치와 문제 알리기 보고서의 내용도 UX 설계에 둠(레이아웃 설계 [[02-layout]]이나 따로 된 문서가 아니라)
