# 토큰과 세션 시간

(← [[atelier/sessions/README|세션 기록]])

AriadneNSD를 만들면서 쓴 토큰과 세션 시간의 누적입니다. 마무리와 매듭 때 `node .claude/scripts/session-usage.mjs`가 Claude Code의 로컬 대화 기록에서 집계해 이 문서를 다시 만듭니다. 손으로 고치지 않습니다.

> [!warning] 집계하지 못한 기간
> 대화 기록은 2026-10-22부터 남아 있습니다. 그 전의 세션 기록 22개(2026-10-07 ~ 2026-10-18)는 토큰과 시간을 알 수 없어 **아래 누적에 들어 있지 않습니다.** 실제 누적은 이 값보다 큽니다.

## 세는 법

- **세션 시간:** 메인테이너와 Claude, 에이전트의 활동 기록을 시간순으로 합쳐, 활동 사이의 간격을 더한 값입니다. 30분이 넘게 쉰 간격은 빼고, 나란히 돈 에이전트의 시간은 한 번만 셉니다. 메인테이너가 화면을 보거나 생각한 시간은 30분 안이면 들어가고, 앱을 따로 써 본 시간처럼 대화 밖의 작업은 들어가지 않습니다.
- **토큰:** 메인 세션과 에이전트의 모든 모델 응답을 응답 하나당 한 번씩 셉니다.
- **캐시 읽기 토큰:** 대화가 이어질 때마다 앞의 내용을 다시 읽은 양이라 합계의 대부분을 차지합니다. 새로 처리한 양은 입력과 출력 토큰으로 보세요.
- **날짜:** 한국 시간 기준입니다. 첫 날(2026-10-22)은 그날의 기록이 일부만 남았을 수 있습니다.
