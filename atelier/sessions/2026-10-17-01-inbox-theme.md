# 2026-10-17 inbox: 문서 구조 기준, 시안 ID, 색 칩, 테마, 부채 정리

2026-10-17의 첫 세션이다 (← [[2026-10-16-01-visual-design]]). 메인테이너의 첫 말은 "안녕하세요"였다. 세션 사이에 메인테이너가 inbox에 여섯 항목을 적어 두었다.

## 논의 흐름

1. **inbox 여섯 항목을 처리 방향과 함께 보여 줌.** 메인테이너: **"하나씩"**. Claude가 첫 항목의 조사부터 시작하자 메인테이너가 끊고 "앞으로 '하나씩'이라고 하면 방금 보여준 질문들, 결정요청들을 하나씩 요청해주세요." → 메모리 `one-at-a-time`
2. **문서 구조 기준** (inbox 1). `docs/`는 최종 결과이고 앱과 동치이며 그 자체로 완결된다, "남은 일"은 `atelier/`로. Claude가 `[!todo]` 콜아웃이 두 가지(아직 설계하지 않은 자리 / 우리가 할 일)로 섞여 있음을 보이고 나누는 법을 추천 → "네, 추천대로 해 주세요". CLAUDE.md에 기준을 적고, `04-design`의 `[!todo]` 25곳을 `[!info] 미완성`으로, [[03-keymap]]의 "남은 일"을 미결정 · 본문 · [[backlog]]로 나눔
3. **시안 ID** (inbox 1). 추천 `M01`~ → "추천 수용". [[sketchbook]]에 M01~M16, 페이지 제목에도 붙이고 claude.ai의 14개를 다시 올림(보조 에이전트). M01(프로토타입)은 올려진 판이 주석 한 줄만 달라 제목만 고쳐 올렸고, 사본 그대로 다시 올리는 것은 자동 모드의 권한 검사가 막음. 메인테이너가 "M01 다시 올려 주세요"라고 해서 갈래 에이전트로 올림
4. **색 코드 옆에 색** (inbox 1). 1번(모든 곳에 칩) → [[04-visual-design]]의 색 코드와 색 토큰 앞에 칩. 스크립트 `journal/assets/2026-10-17-add-color-chips.py`
5. **테마** (inbox 5). 메인테이너: 색 정의는 테마에 속하고, 밝은 · 어두운은 테마의 종류, 지금은 종류마다 기본 하나씩. 시안 M17로 물음: TH1 그림의 테마는 누가 고르는가 → 메인테이너가 "2"라 했다가 곧 "1"(문서마다, 파일에 저장). TH2 편집 화면의 색도 테마에 넣는가 → 1(따로, "화면 색"). 문서 전체에서 "문서 팔레트" → "테마", "UI 테마" → "화면 색"
6. **해결된 부채와 할 일 찾기, 부채를 종류별로** (inbox 1). 해결된 것 11개를 먼저 보여 줌 → "네, 지우고 묶어 주세요". 부채를 주제별로 다시 묶음(일곱 주제)
7. **호출 대상** (inbox 3 "호출할 서브루틴이 없거나 다른 문서에 있을 수도 있음"). 시안 M18: CB1 1번(이름을 적는 호출 블록, 보통 모양), CB2 1번(파일과 Method를 가리켜 둠), 우선순위 #P1 · #P2 "추천 수용"
8. **inbox 비우기.** "모두 옮기고 지우세요." 접기 영역 테두리 색이 M11과 다른 까닭(같은 파랑이라 헷갈려서)에 동의하면서 **"접기 영역 테두리 색상은 마음에 안 듭니다."**
9. **접기 영역과 고른 표시의 색** → 시안 M19. 메인테이너의 요청으로 B안(접기 영역은 이전 파랑, 고른 표시의 색을 바꿈)을 더하고, 겹치고 이어진 접기 영역을 넣고, **"보여주시는 시안의 테두리 모양이 M11의 T1에서 3번째 카드 나의 선택과 다릅니다. 이러면 내가 선택하기가 어려워요."** → M11의 코드를 그대로 가져와 다시 그림(메모리 `reuse-chosen-drawing`). "선택이 가장 위에 나와야합니다" → 고른 표시를 맨 위 층으로. S3(녹색)을 골라 54번째 판, 이어서 "3px 그리고 S1으로 프로토타입 다시" → 55번째 판, "선택도 3px, s2도 봅시다" → 56번째 판(색을 고르는 임시 선택), "지금 모습이 마음에 듭니다" · "S1" → 57번째 판
10. **옛 키.** "접기 영역 설정하는 단축키가 뭐지요?" · "ctrl+f는 없어졌나요?" → "옛키도 살려주세요" → `Shift`+`F`(58번째 판. `Ctrl`+`Shift`+`F`는 그동안에도 들었음). "겹치지 않는 것들은 되살리되, 되살렸을 때 사용자가 혼란스러울 것들이 있는지 검토해주세요" → `w` / `W`, `Shift`+`L`(59번째 판). "w은 뺍시다" → 60번째 판
