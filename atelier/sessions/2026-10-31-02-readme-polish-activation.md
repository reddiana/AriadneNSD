# 2026-10-31 README 첫 화면 다듬기(시안 M42), 시퀀스 다이어그램의 활성 막대, 프로토타입 63번째 판

(← [[2026-10-31-01-readme-prototype-62]]) 메인테이너: "다시 잠깐 들어왔어요. inbox만 체크해주세요." inbox의 세 항목을 그 자리에서 처리했다.

## inbox

세 항목을 함께 검토했고, 마무리 때 "원문을 옮기고 지움"을 골랐다. 원문:

> # 6. 기타
> - README의 퍼블리싱에서 
> 	- AriadneNSD 프로토타입 링크가 너무 눈에 안뜨입니다.
> 	- 샘플 다이어그램의 바탕이 하얀데, 문서는 색상이 있어서 보기에 예쁘지 않습니다. 좋은 방법 없을까요?
> - 퍼블리싱된 시퀀스다이어그램의 액티브바가 너무 색이 진합니다. 꽤 연한 색으로 고쳐주세요.
> - 

## 논의 흐름

1. **inbox만 보기.** 세 항목의 처리 방향을 제안했다. 메인테이너가 펴낸 사이트와 Obsidian에서 변화를 찾았으나, 아직 아무것도 고치지 않은 때였다(제안만 했다는 것을 분명히 말하지 못함). "네, 시작해 주세요. push해도 됩니다."
2. **시퀀스 다이어그램의 활성 막대.** Mermaid의 기본색(`secondaryColor`, 짙은 남색)이 막대에 쓰였다. 사이트는 `site/custom.scss`에서 `--tertiary`를 22% 섞은 연한 색으로(밝은 · 어두운 테마 함께), Obsidian은 CSS 조각 `.obsidian/snippets/mermaid-activation.css`를 만들어 `appearance.json`에서 켰다. `.obsidian/`은 git에 들지 않는다.
3. **README 첫 화면(시안 M42).** (가) 그림의 하얀 바탕: 가1 지금 · 가2 종이 카드 · 가3 밝은 테마는 녹이기. (나) 프로토타입 링크: 나1 지금 · 나2 그림 아래 큰 버튼 · 나3 맨 위 버튼. 메인테이너는 가2를 골랐고, (나)는 "M41의 버튼처럼" → 나4~나6, "나5에 더해서 M41처럼 다이어그램마다 작은 버튼" → 나7, "M41처럼 다이어그램 왼쪽 아래에 … 아래 큰 버튼은 나2" → 나8, 큰 버튼을 인용절 아래로, 글을 "프로토타입 편집기에서 열기" · "프로토타입은 요구사항을…"으로. 이어서 "'프로토타입 써 보기'는 나1로 … 링크만 눈에 띄게" → 나9 색과 밑줄 · 나10 작은 버튼 · 나11 채운 버튼. **나11**을 고름.
4. **반영.** 버튼은 Pretendard(OFL)의 글꼴 모양을 선으로 옮긴 SVG 그림으로 만들어 GitHub · 사이트 · Obsidian에서 같게 했다(`journal/assets/2026-10-31-readme-buttons.py`). 그림마다 버튼을 달려고 README는 표를 썼고, 사이트에서는 표의 선을 지웠다. 버튼이 그 예제를 열도록 프로토타입 **63번째 판**에 주소로 예제 열기(`#dijkstra` · `#merge-sort`)를 넣었다.
5. **펴낸 것을 보고 되돌림.** "가1로 원복해주세요. '프로토타입 편집기에서 열기' 버튼도 제거해주세요." 그림 바탕은 그대로, 작은 버튼과 그 그림 · 꾸밈을 뺐다. 프로토타입의 주소로 여는 기능은 해가 없어 남겼다.
6. **인용절 다듬기.** 버튼은 새 창으로(`target="_blank"`, GitHub는 이 속성을 지움), 버튼을 제 줄에. 빈 줄로 나눈 단락 셋은 사이트에서 간격이 넓어 한 단락 안의 `<br>`로 바꾸고 버튼의 위아래 여백을 4px로. "시안과 프로토타입" 절의 프로토타입 링크도 새 창으로. 메인테이너: "마음에 듭니다."

## 결정

- README 첫 화면: 인용절의 프로토타입 링크는 채운 버튼 그림(시안 M42의 나11), 새 창, 제 줄. 그림 바탕은 그대로(가1) → `README.md`, [[sketchbook]]의 M42
- 시퀀스 다이어그램의 활성 막대는 연한 색 → `site/custom.scss`

## 발견한 위험

- 이 PC의 셸에서 Node를 찾지 못했고 헤드리스 Chrome 실행은 권한에서 막혔다. 프로토타입 63번째 판을 시험하지 못했고, 버튼 그림 · 사이트 꾸밈도 화면으로 보지 못했다(메인테이너가 펴낸 사이트를 보고 판단) → [[prototype#시험한 곳과 못 한 곳]]
