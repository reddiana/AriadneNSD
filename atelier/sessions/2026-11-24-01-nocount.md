# 2026-11-24 메인테이너의 방문을 방문 수에서 빼기(?nocount)

"cloudflare Web analytics에서 내가 접근한 것을 제외할 수 있나요?"로 시작했다. inbox는 비어 있었다.

## 논의 흐름

- Cloudflare Web Analytics에는 방문자 · IP를 빼는 설정이 없다. 두 길을 비교: 코드에 `?nocount` 표시(추천) · 광고 차단기로 신호기 막기.
- "여러 번 접속하면 중복으로 카운트 되나요?": 쿠키가 없어 들어올 때마다 따로 센다(Visits · Page views, 순 방문자 수 없음) → [[web-analytics]]
- 메인테이너가 1번(`?nocount`)을 고름. 주로 쓰는 브라우저가 Edge라고 해서, 브라우저 · 프로필 · 기기마다 한 번씩, InPrivate과 데이터 지우기 뒤에는 다시 열어야 한다고 알림.
- 메인테이너가 "그냥 `?nocount`로 접속하면 된다고 했잖아요? 뭘 개발했다는 것이죠?"라고 물음. 처음 설명이 이미 있는 기능처럼 읽혔다. 새로 만든 것이고 push 뒤에야 듣는다고 다시 설명.

## 결정

- `?nocount` → `localStorage`의 `ariadne-nsd.setting.nocount`, `?count`로 지움, 다섯 곳(앱 · 사용법 en/ko · 갤러리 · Quartz) `9b2c94b` → [[06-web#5.2 방문 수]], [[0051-cloudflare-web-analytics|ADR-0051]]의 이후 변경

## 배운 것

- 제안할 때 "이미 있는 것"과 "만들어야 하는 것"을 첫 줄에서 갈라 말한다.
