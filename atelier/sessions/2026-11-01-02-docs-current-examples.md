# 2026-11-01 문서 현행화, MVP에 예제 넣기

메인테이너: "잠깐 들어왔어요. inbox만 체크해주세요." → inbox의 둘(문서 현행화)을 보고 처리 방향을 알림. 메인테이너: "1, 2 다 진행해주세요". 그 사이 inbox에 하나(MVP에 예제 넣기)를 더함.

## inbox에서 옮긴 원문

`6. 기타`:

- 최상위 README에 Note로 코드는 없다고 되어있네요. 현행화 해주세요.
- 이참에 다른 문서도 현행화 점검해주세요.

`3. 기능` › `## MVP`:

- 프로토타입에 있었던 예제들 삽입하는 기능을 가져옵시다. 
	- 메뉴 위치는 "도움말>예제". 모든 예제가 같은 레벨.
	- 툴바에도 예제를 넣고 드롭다운으로 고를 수 있게
	- 첫 방문이면 예제를 보시겠느냐 물어봐줍시다.

## 문서 현행화

- 코드가 없던 때의 문장을 고침: `README.md`의 Note(지금은 MVP 웹을 개발 중, 코드는 `src/`), `CONTRIBUTING.md`(MVP 써 보고 버그 알리기를 더함, 코드는 `src/README.md`, 코드 Pull Request는 아직 받지 않음), CLAUDE.md의 `CONTRIBUTING.md` 줄, [[03-quality-attribute-scenarios]]의 읽는 법, [[model-layout-render-theme]]에 MVP 코드의 자리를 덧붙임
- DR-0005 · DR-0008의 "코드가 아직 없다"는 그때의 결정 근거라 그대로 둠

## MVP에 예제 넣기

- 예제는 프로토타입의 열둘 가운데 겹치는 둘("문장식": "코드식"과 같은 로직, "이진 탐색(한 장)": "이진 탐색"과 같은 알고리즘)을 뺀 열(메인테이너: "겹치는 것 빼고 10개 (추천)")
- 메뉴는 도움말 › 예제 ▸, 모두 같은 레벨. 툴바에도 예제 드롭다운
- 첫 방문이면 모달로 묻되, 드롭다운이 아니라 예제 목록을 한 번에 다 보여 줌(메인테이너: "1.번이 좋은데 드롭다운 말고 예제 목록을 한번에 다 보여주세요. 3*4나 4*3이면 한번에 다 보여줄 수 있겠네요.")
- 예제를 열면 "새로"와 같음: 저장 안 된 문서를 바꿀 때 웹은 묻지 않음(임시 보관이 있어서, [[03-editor#6. 셸과의 연결]])
