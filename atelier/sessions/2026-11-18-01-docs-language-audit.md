# 2026-11-18 문서의 말, 어긋남 정리, 설계 전수 대조

2026-11-18 밤부터 11-19 새벽까지 이어진 세션이다. inbox에서 시작해 문서의 말과 원칙을 정리하고, 시각 디자인의 어긋남을 하나씩 정한 뒤, 설계 문서와 앱을 전수 대조했다.

## 논의 흐름

1. **inbox 처리:** About의 문서 · 저장소 링크, C&C 범례를 그림 아래로, 테스트 문서를 아키텍처 폴더로, 지금의 커버리지를 [[coverage]]로 옮겼다.
2. **펼친 호출 블록:** 메인테이너: "호출블록 펼치기는 접기영역 펼치기에서 선과 띠 색상만 보라색 계열로 해주세요." 시안 M60을 보고 구현했다. 이것으로 M59의 물음(CP1)은 끝났다.
3. **시각 디자인 현행화:** 어긋남 8건을 시안 M61 ~ M67로 하나씩 정했다(IE1, AR1, SL1, NT1, KA1, EX1, WC1, FD11 → [[ux-decisions]]). BUG-15 · BUG-17을 고치고 해부도를 완성했다.
4. **문서의 말:** "표기법"은 "범례"로. 문서 전체를 아키텍트와 프로그래머의 언어로 고치고 대응표를 [[how-we-work#문서에서 쓰는 말]]에 두었다. 정규식 치환이 조사와 뜻을 망가뜨려 바뀐 837줄을 전수 교정했다.
5. **문서화 원칙:** 메인테이너: "우리의 문서와 어플리케이션은 마치 회계장부의 대변과 차변처럼 서로의 더블입니다." "디자인과 설계는 어플리케이션을 충분히 표현해야합니다."
6. **품질 시나리오:** QA 제목을 포멀하게 고치고 시나리오마다 의도와 배경을 더했다.
7. **호출 지점별 접힘:** 메인테이너: "호출 블록은 처음 펼칠 때만 영향을 받습니다." CB13과 ADR-0046으로 구현했다.
8. **누적 기록:** 토큰과 세션 시간을 [[usage|토큰과 세션 시간]]에 집계한다. 비용은 뺀다.
9. **설계 전수 대조:** 342건 가운데 상 65건을 처리했다. 문서와 앱이 다른 14가지는 메인테이너가 모두 추천안대로 정했다(UX 결정 CV1).
10. **겹친 테두리:** 메인테이너: "호출블록과 접힘영역은 펼침, 접힘이 동일한 UX 기준을 가지는 것입니다." 제어 블록을 거쳐 겹친 테두리도 바깥 테두리와 1px 띄운다(UX 결정 NF1).

## 결정

- UX 결정: IE1, AR1, SL1, NT1, KA1, EX1, WC1, FD11, CB13, CV1, NF1 → [[ux-decisions]]
- 호출 지점별 접힘: ADR-0046
- 대조의 근거: `journal/assets/2026-11-19-design-coverage-audit.md`, `journal/assets/2026-11-19-design-coverage-conflicts.md`

## 마지막 검사 (2026-11-19 새벽, 커밋 aa2c710)

| 검사 | 결과 |
| --- | --- |
| `pnpm check` | **실패.** core 484건 중 T-0171(5초 시간 초과)과 T-1126(100ms 한도) 2건 |
| core를 파일 하나씩 차례로 실행(3회) | 484건 모두 통과 |
| editor · web · fonts | 894 · 276 · 31건 통과 |
| typecheck · lint · format · deps · 생성 문서 검사 | 통과 |
| `pnpm e2e --workers=1` | 83건 통과 |

T-0171은 이 세션을 시작한 커밋(54f2bcc)에서도 3회 모두 실패했고, T-1126도 3회 중 1회 실패했다. 테스트 파일을 나란히 돌릴 때만 실패하므로 이번 변경이 만든 결함이 아니라 시간에 묶인 테스트의 불안정으로 판단해 push했다. 다만 겹친 테두리 수정이 500블록 레이아웃을 약 3 ~ 4% 느리게 해 T-1126의 실패가 늘었을 수 있다. CI도 같은 까닭으로 실패할 수 있다.

## 발견한 위험

- 시간에 묶인 테스트 때문에 `pnpm check`가 이 기계에서 안정적으로 통과하지 못한다.
- E2E T-0012는 저장이 끝나기 전에 파일을 읽는 경쟁 상태가 의심된다(한 번 실패, 그 뒤 모두 통과).
- 옆 분기에 나란한 두 테두리는 분기 사이의 선에서 만난다(틈 0px).
