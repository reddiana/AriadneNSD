## 매듭 뒤: GitHub에서 그림이 위아래로

메인테이너: "대문 readme에 폭이 좁은 화면에서 중앙정렬이 잘 됩니다. 그런데 github에서 예전에는 좌우로 보이던 화면 사이즈에서 지금 상하로 보이네요. 물론 화면 사이즈가 충분하면 좌우로 보입니다."

- 원인: GitHub은 `style`(flex · gap)을 지우므로, 그림 폭과 여백의 합이 한 줄에 들어가느냐가 전부임. 예전(`&nbsp;` 두 칸)은 약 604px, 지난 세션에 넣은 `hspace="8"`은 약 622px가 필요했음
- `hspace="4"`로 줄임(약 606px). 양옆이 같은 여백이라 좁은 화면의 가운데 맞춤은 그대로
- 메인테이너가 GitHub과 좁은 화면에서 확인함: "잘 적용됐습니다. 마음에 듭니다." 그래서 [[outbox]]의 "README 첫 화면의 그림을 MVP 예제의 `.ns.svg`로 바꾼 것"(휴대폰에서 가운데로 오는지 봐 주기)을 지움
