# 2026-10-15 inbox 검토: 저장소 이름, 고른 것 풀기, 휠, 위로 갈 때의 갈래

2026-10-15의 첫 세션이다 (← [[2026-10-14-01-inbox-ide-plugin]]). 메인테이너의 첫 말은 "inbox 체크해주세요."였다.

## 논의 흐름

1. **inbox 세 줄.** 저장소 이름을 바꿨다는 알림 하나와 프로토타입 요청 둘(고른 것 풀기, 마우스 휠). Claude가 저장소 이름이 적힌 곳을 찾고(파일 17개, git 원격 주소, 승인된 ADR-0019와의 어긋남) 처리 방향을 한 번에 적었다. 고른 것 풀기와 휠은 말로 고를 선택지를 따로 만들지 않고, 기본값으로 프로토타입에 넣어 써 보시게 하자고 했다.
2. **"그리고 if나 case 제어블록 아래 블록에서 `j`하면 …"** 말로 하나가 더해졌다. 아래 블록에서 `j`는 아래로 가는 키라 갈래로 들어갈 일이 없어서, Claude가 `k`로 읽고 지금 동작(가장 오른쪽 갈래로 감)과 바꾼 뒤의 동작을 글 그림으로 보였다. "k가 맞아요. 잘 이해하셨어요."
3. **프로토타입 52번째 판.** 넷을 넣고, 고른 블록을 화면이 따라가게 했다(휠로 내려가다 화면 밖으로 나가면 쓸 수 없어서). 헤드리스 Chrome 시험을 12개 더해 164개가 통과했다.
4. **저장소 이름.** ADR-0028을 쓰고 출처 표기 주소를 고쳤다. claude.ai의 시안 12개를 다시 올렸다. 올라가 있던 판은 주소 줄 말고는 저장소의 사본과 같았다.
5. **"로컬 repo 디렉토리명도 바꾸려고 합니다. 내가 직접 바꿔야하지요?"** 이 세션이 그 폴더 안에서 돌고 있어서 세션을 끝낸 뒤 메인테이너가 바꾸기로 했다. Claude Code의 메모리 폴더는 폴더 경로에서 이름을 따므로, 마무리 때 Claude가 새 이름으로 복사해 두었다.
6. **"마무리"** 아키텍처 초안의 확인 일곱은 이번에도 다음으로 넘어갔다.

## 발견한 것과 위험

- **UX 물음 Q19와 어긋난다.** Q19의 추천 1은 "언제나 무언가 골라져 있다"였다. 고른 것을 푸는 방법이 생겨 그대로 둘 수 없게 되었다. "명령이 끝난 뒤 무엇이 골라지는가"는 아직 남았다 → [[05-ux-decisions]] Q19
- **휠은 진짜 마우스로 시험하지 못했다.** 스크립트가 만든 가짜 이벤트로만 시험했다. 마우스 휠 한 칸의 크기(대개 100px)와 터치패드의 작은 움직임이 실제로 어떻게 오는지는 써 봐야 안다 → [[prototype#시험한 곳과 못 한 곳]]
- **옛 저장소 주소는 GitHub이 넘겨 주지만, 누가 그 이름으로 새 저장소를 만들면 넘김이 끊긴다.** 그래서 출처 표기 주소를 고쳤다. 다른 사람이 이미 옮겨 적은 옛 주소는 고칠 수 없다.
- **폴더 이름을 바꾸면 Claude Code의 메모리가 따라오지 않는다.** 복사해 두었지만, 새 폴더에서 처음 열 때 메모리를 읽는지는 다음 세션에서 확인해야 한다.

## inbox 원문 (지운 항목)

"1. 일하는 방식"에 있었다.

> - 저장소 이름을 변경했습니다.
> 	- before: https://github.com/reddiana/ariadne-nsd.git
> 	- after: https://github.com/reddiana/AriadneNSD.git

"3. 기능 › 프로토타입 › 추가/변경 요건"에 있었다.

> - 아무것도 셀렉트 되지 않은 상태로 해주세요. 
> 	- `ESC` 두번 연속 누르면 
> 	- 다이어그램 외부 캔버스 빈 공간을 마우스 클릭하면
> - 마우스휠은 
> 	- 블록 셀렉트한 상태에서는 위아래 방향 이동과 동일하게 해주세요.
> 	- 블록 셀렉트하지 않은 상태에서는 캔버스 스크롤

세션 중에 말로 하나를 더했다(inbox에는 적히지 않음).

> 그리고 if나 case 제어블록 아래 블록에서 `j`하면 가장 왼쪽 브랜치의 제일 아래 블록으로 이동하게 해주세요.

Claude가 "`k`(위로)를 말씀하신 것 같다"고 되물었고, 메인테이너가 "k가 맞아요. 잘 이해하셨어요."라고 답했다.
