# 2026-11-22 홍보 준비, 알고리즘 갤러리

"홍보를 하고 싶습니다. 알고리즘에 관심이 많은 프로그래머들에게 어필할 수 있을 것 같아요."로 시작했다. 첫 수로 알고리즘 갤러리와 글 한 편을 고르고, 갤러리 페이지(M70 G3)와 GeekNews · Show HN · Reddit 초안을 만들었다.

## 논의 흐름

1. **CONTRIBUTING.** inbox 항목대로 "MVP를 개발하고 있다"를 "웹 베타"로(한국어 · 영어, `241c390`). 홍보로 들어온 사람이 처음 볼 문서라 먼저.
2. **첫 수.** 선택 창에서 "갤러리 + 글"(추천안). 갈고리는 ① 알고리즘을 구조로 읽기, ② 코드를 주면 그려 주는 Claude 스킬.
3. **묶음.** 선택 창에서 고전 · 어려운 것 · 재미 셋 다. 에이전트가 16개를 그림(BFS · DFS를 나눠 앱 예제 6개와 합쳐 22개, `56c1529`). 생성 스크립트 `gallery-images`가 `.ns.svg` 44개와 `gallery.json`(공유 링크 포함)을 만든다.
4. **M70 배치.** G1 카드 그리드(추천) · G2 한 장씩 크게 · G3 목록 + 큰 그림. 메인테이너가 G3를 고름. 에이전트가 `src/apps/gallery`로 페이지를 만들어 사이트 빌드에 연결(`0756e96`): `#kmp` 바로 가기, ↑ ↓, 휴대폰은 select, 넓은 그림은 칸 안에서 가로 스크롤, 새 OG 그림, 사용법 "예제" 꼭지에 링크.
5. **정확성.** 다른 에이전트가 그림의 블록을 Python으로 그대로 옮겨 기준 구현 · 브루트포스와 견줌. 16개 모두 맞음, 고친 것 없음(`17fc681`, `src/apps/gallery/verify/`).
6. **글 초안** → [[promotion]]
	- 메인테이너: "GeekNews에 정보처리기사 얘기는 빼주세요. 알고리즘 관심있는 한국 개발자들이 오히려 정보처리기사를 얕보는 경향이 있는 것 같습니다."
	- 메인테이너: "'다시 열어 편집할 수 있는 원본'이란 말은 한국 개발자들에게 잘 와닿지 않습니다." → README에 넣으면 그림으로 보이고 편집기로 다시 열면 고친다는 장면으로.
	- 메인테이너: "GeekNews가 마음에 안 드네요. 너무 AI가 작성한 티가 납니다." → 굵은 글씨 · 대칭 글머리표를 없애고 커뮤니티 말투로. 메인테이너의 경험은 지어 쓰지 않고 빈칸으로.
	- 메인테이너가 빈칸에 만든 까닭(플로우차트는 지면을 차지하고 NS 차트는 지우개로 다시 그려야 했다)을 썼다. Show HN에도 영어로 넣음. "met in school" · "helps you the way it helps me"는 그대로, "재미있던 것 한 줄" 빈칸은 뺌.
