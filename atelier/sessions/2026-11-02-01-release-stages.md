## MVP 다음은 무엇인가

- 찾아보니 "베타"는 정의 없이 쓰인 말이었다: 후원 버튼("웹버전 베타버전 출시하면 합시다", 2026-10-10), 비공개 문제 알리기 채널("웹 베타 무렵"), 상표 검색("공개 출시 전"), `P3`("출시 뒤"). 파일 형식 명세의 "첫 출시 전까지는 버전을 올리지 않고 고칠 수 있다"는, MVP를 "첫 출시"라고 부르는 지금 뜻이 엇갈렸다.
- 정해져 있던 것은 둘뿐이었다: 웹은 MVP에서 미룬 기능을 다음 판들에(DR-0015), 배포 대상은 웹 → Obsidian → 데스크톱(DR-0002).

## 버전 0.1.0, 1.0 전 파일 알림, README 로드맵

메인테이너: "지난번 push한 CI와 Pages가 통과했습니다. 8과 9를 먼저 해 주세요 / 우리의 로드맵을 README에서 방문자들에게 안내해주면 좋겠어요."
