# 2026-11-28 문서에서 쓰는 말을 원칙으로

허브([[2026-11-28-09-hub-control-and-tokens|세션 09]]의 허브)가 연 서브 세션입니다. 주제 하나: [[how-we-work#문서에서 쓰는 말]]의 검토.

## 흐름

- 메인테이너: "how-we-work에서 '문서에서 쓰는 말'을 검토하겠습니다. 이렇게 매핑표를 넣기 보다 원칙을 정하는 것이 더 좋지 않을까요?"
- 표 54줄을 살펴보니 대부분이 세 원칙(업계 말로 · 번역해 짓지 않기 · 코드 동작에 일상어 빌려 쓰지 않기)에서 바로 나오고, 문맥에 따라 갈리는 말(조각 → 슬라이스 · 청크)과 설계 문서에만 적용하는 말(그림 → 렌더링 등)만 원칙으로 정해지지 않았다.
- 물음 1(절의 모양): 원칙 + 짧은 목록 / 원칙만 / 원칙 + 표 전체 → 메인테이너는 "원칙 + 짧은 목록"을 골랐다.
- 물음 2(적용 범위): 원칙마다 나눔 / 모두 모든 곳에 / `docs/`만 → 메인테이너는 "모두 모든 곳에"를 골랐다(대화와 모든 문서, 지난 세션 기록은 그대로, 다른 문서는 고칠 때 맞춤).

## 결정

- "문서에서 쓰는 말"을 원칙 다섯(업계 말로, 번역해 짓지 않기, 코드 동작에 일상어 빌려 쓰지 않기, 제품 고유의 말과 화면 문구는 그대로, 정한 말은 그 말로)과 정한 말 13개의 목록으로 바꿨다. 목록의 말은 괄호 안의 뜻으로 쓸 때만 바꾼다. 그림 · 글자 · 자리 · 적다는 지금처럼 설계 문서에만 적용한다.
- DR은 쓰지 않았다(일하는 방식의 작은 변경, how-we-work만 고침).
- 메모리 `use-common-ux-terms`에 원본 링크와 바뀐 범위를 더했다.

## 발견

- CLAUDE.md의 제품 말 예시 "갈래"는 옛 말이다(용어집은 "분기").
- `doc-check.py`를 파일 인자만 주고 부르면 stdin을 기다리며 멈춘다. 문서 하나를 검사할 때도 `--all`로 돌리고 출력을 걸러 봐야 한다.
