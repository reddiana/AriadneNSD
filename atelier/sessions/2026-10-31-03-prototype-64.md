## 결정

- **머리 모양의 기억과 기본값** → [[ux-decisions#HS1. 머리 모양을 기억하고 기본은 제목처럼|HS1]], 규칙 [[02-interaction-rules#머리 모양]]. 머리 모양은 그대로 문서 설정이고, 마지막으로 고른 것을 사용자 설정으로 기억해 새 문서의 처음 값으로 쓴다. 파일을 열면 파일의 값, 연다고 기억이 바뀌지 않음, 머리 모양이 없는 예전 파일은 "모자 · 아치"는 Claude가 정함
- **처음 방문하면 Raft 예제**: 메인테이너의 말대로 프로토타입에만. 제품의 처음 화면은 정하지 않음
- **열면 고른 것이 없다** → [[ux-decisions#OP1. 열면 고른 것이 없다|OP1]], 규칙 [[02-interaction-rules#키보드로 이동하고 넣기]]. "새로"(빈 문서)는 빈 블록을 고른 채로 두는 것은 Claude가 정함
- **좁은 화면** → [[ux-decisions#MB1. 좁은 화면|MB1]], 원칙 "화면은 다이어그램에게"([[01-ux-overview#2. UX 원칙]]). 단추의 자리와 모양은 편집기 설계로 미룸

## 웹 화면 설계 (시안 M44, 매듭 뒤)

메인테이너: "웹 화면 설계 합시다". 시안 M44(https://claude.ai/artifact/VpocjhpW3vtPJ8UHvoyFgX, 사본 `journal/assets/2026-11-01-web-screen-study.html`)를 일곱 판까지 고치며 W1 ~ W6을 하나씩 정했다 → [[ux-decisions#11. 웹 화면 (2026-11-01)]], [[06-web#7. 화면 배치]]

- W1: 첫 판은 SequenceDiagram.org식 왼쪽 아이콘 막대를 추천했다. 메인테이너가 Structorizer를 참고하자고 해("structorizer의 아이콘바에 블록들이 있는 것이 편해보입니다") 블록 모양 아이콘을 넣어 다시 그렸고, 메뉴 막대 + 블록 아이콘 도구 모음으로 정함
- W2: 메인테이너가 끌어 놓는 자리의 규칙을 직접 제안했고, 누르기 규칙은 Claude의 추천(누르기는 언제나 넣기, `Ctrl`+클릭은 감싸기)을 받아들임
- 메인테이너가 중간에 "설계 문서에 반영해주세요", "VSCode나 IntelliJ 같은 IDE를 참고해봅시다", "w3도 다른 ide를 참고해서 의견 주세요"라고 해, 정할 때마다 문서에 옮기고 IDE의 모습을 표로 견주었다. W3은 "탭이 하나 뿐일 때는 탭을 안보이게 하는 UI도 쓰이는 사례가 있나요?"에서 macOS식(하나면 탭을 숨김)으로
- W3-b 자동 저장 기본 켬, W4 새 탭의 사용법과 `?` 겹창, W5 설정 창 둘(Claude의 추천은 창 하나였음), W6 명령 찾기를 새 요구사항 [[01-requirements#^r-edit|R-EDIT-24]]로 MVP에
- Claude가 정한 세부 가운데 셋을 짚어 물었고 메인테이너가 확인함: "확인 요청한 세가지 모두 ok입니다" (빈 블록 위에 놓으면 그 빈 블록을 바꿈, 자동 저장은 고치고 2초 뒤, 명령 찾기에서 듣지 않는 명령은 흐리게). 나머지 세부(W2의 넷, W3의 셋, W3-b · W5 · W6의 키와 최근 명령)도 이어서 확인함: "모두 ok입니다"
- M43의 그림 묶음에 W2 장면을 더할 때, 다시 뽑으면 65번째 판의 동작(빈 머리 이름)이 M43의 그림에 섞여 예전 그림을 지켰다

[[06-web]]에 파일 열기 · 저장(Chromium과 그 밖의 두 흐름), 최근 파일, 임시 보관의 흐름. 절 번호가 바뀌어 "5. 셸과의 연결" 링크 넷(승인된 ADR 둘 포함, 주소만)과 지난번에 바뀐 "갈래 순서 바꾸기" 링크 둘을 고침. Claude가 정한 세부는 [[outbox]]

메인테이너: "'겹'은 '레이어'를 말하는 것 같습니다. UX에 관련된 것은 보편적으로 많이 쓰이는 UX 전문가의 용어를 써주세요. 굳이 순한국어를 고집할 필요 없습니다." 범위를 물어 "UI 요소 이름 + 선택"으로 정하고 docs/ 전체(18개 문서, 330줄)를 바꿈: 층 → 레이어, 도구 모음 → 툴바, 메뉴 막대 → 메뉴 바, 오른쪽 클릭 메뉴 → 컨텍스트 메뉴, 명령 찾기 → 커맨드 팔레트, 상태 줄 → 상태 표시줄, 겹창 → 모달, 끌어 놓기 → 드래그 앤 드롭, 놓을 자리 → 드롭 위치, 세모 → 펼침 삼각형, 고른 표시 → 선택 하이라이트, 글자 칸 → 인라인 에디터, 안내 상자 → 키 힌트, 마우스 올림 → 호버, 고르다 → 선택하다. 받침에 따라 틀어진 조사를 고치고, 바뀐 절 제목을 가리키는 링크를 맞춤(docs → UX 결정 모음은 결정 모음의 제목 그대로, atelier → docs는 새 제목으로). atelier/의 지난 기록은 그때의 말 그대로 둠. 방침은 Claude의 메모리에도 남김
