# 2026-11-28 조작 규칙의 표 대조 테스트

본체가 연 분신. [[2026-11-28-17-interaction-abstraction-review|추상화 검토]]의 0단계 다: 조작 규칙의 공통 규칙에 있는 표를 명세로 삼아, 편집기가 표와 같은지 대조하는 테스트를 만들었다. 브랜치 `claude/objective-dewdney-9764db`(worktree `lazy-locales-45736f`). 앱 코드는 고치지 않았다.

## 흐름

1. **과제**(본체): 표의 한 칸이 테스트 하나에 대응해 표가 바뀌면 테스트가 드러나게. 표와 코드가 다른 곳은 고치지 말고 보고.
2. **테스트**(`a9163b7` · `45dcba8`, T-1700 ~ T-1721, `src/packages/editor/src/rules/`): 요소와 컨테이너(T1 ~ T4 포함), 블록 종류, 텍스트 필드, 명령마다 받는 대상의 표 1 · 2, 삽입 위치(키보드 삽입 · 붙여넣기와 드롭), 명령 × 대상 매트릭스. 나란히 구현 중이던 BL3 · BL4의 칸은 skip
3. 메인테이너에게 merge를 물음: "merge (추천)"(선택지에 "merge한 뒤 BL3 · BL4를 기다리던 테스트를 켭니다"). 본체가 `28f2ec1`로 merge
4. 본체: BL3 · BL4 · UN3가 `main`에 있으니 켤 것. `main`을 받아(`3dbdd6f` · `2bd1e01`, 충돌은 테스트 목록과 `test-ids.json`) 보류한 칸을 모두 켜고 보류를 위한 틀을 걷음
5. 설계 [[03-editor]] 3.5에 테스트를 적고 [[backlog#조작 규칙과 설계의 추상화]]를 갱신. 새 규칙(소임을 다 하면 스스로 보관)에 따라 이 기록을 쓰고 보관

## 결정

메인테이너의 결정은 merge 하나다.

## Claude가 정한 것 (확인받지 않음)

- **표는 문서에서 파싱하고, 칸의 문구와 기대 동작은 테스트에 옮겨 적는다.** 칸은 한국어 서술이라 파싱만으로는 실행할 수 없고, 옮겨 적기만 하면 문서가 바뀌어도 테스트가 알지 못한다. 대신 칸의 문구를 다듬기만 해도 테스트의 문구를 함께 고쳐야 한다
- 테스트 ID는 표마다 하나(`it.each`)와 표의 모양을 확인하는 것 하나. 칸은 테스트 이름의 "행 × 열"로 가리킨다
- 테스트 목록의 영역은 "문서와 코드의 정합성"

## 표와 코드가 다른 곳 (고치지 않음)

1. 이름 띠를 끈 접기 영역에 접기 · 펴기를 적용하면 알림이 어디에 적용했는지 말하지 않는다(T4 · C1, 이미 U7). T-1720, skip
2. 빈 default 칸의 접기 영역 풀기: 표 1 · 2대로면 그 Case를 담은 접기 영역이 풀려야 하는데 매트릭스는 "거절"이고 코드도 거절(표끼리 다름, 이미 backlog의 결함 후보). T-1721, skip
3. 빈 괄호의 Method(`reset()`)를 호출해 삽입하면 인자 필드가 열린다. "호출 블록" 절의 문장은 받는 것이 없는 것으로도 읽힌다
4. 문서의 빠짐: 표 1의 "접기 영역" 줄의 사슬에 바깥 접기 영역이 없다(코드는 거친다)

## 발견한 위험

- BL3 · BL4의 칸(매트릭스 3, 삽입 위치 1, 표 2의 2)은 문서가 아직 예전 문구인데 테스트는 새 동작을 확인한다. 테스트의 주석에 적었다. 문서를 정리할 때 `doc` 문구를 함께 고친다
- 표 1의 확인은 `foldTargets` · `unwrapHolder` · `regionToRemove`를 직접 호출한다. 1단계에서 대상 해석기로 바꾸면 `table-targets.test.ts`도 고친다
- BL3 · BL4의 merge에서 T-0558(명령을 쓸 수 없는 까닭의 표)의 `block.insert.if` · `block.insert.call` 줄이 통째로 빠졌다. 거절 말고 "적용됨"을 확인하던 선택들도 함께 없어져, 실행되는 경우가 29개 줄고 14개 늘었다(editor 전체 1384 → 1368의 대부분. 하나는 이 분신이 걷은 중복 테스트)

## 확인한 정도

- 최신 `main`(`4824080`)을 받은 뒤: editor 테스트 1366개 통과, 2개 skip(`SKIP_TIMING=1`). 타입 검사, 포맷, 테스트 목록 검사 통과. 의존 검사는 첫 merge 뒤에 통과. editor의 lint 통과
