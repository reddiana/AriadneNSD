# 아틀리에 (작업 공간)

메인테이너와 Claude가 지금 하고 있는 일이 모두 여기서 일어납니다. 지금 어디에 있는지([[status]]), 무엇이 남았는지([[backlog]]), 메인테이너의 답을 기다리는 것([[debt]]), 프로토타입의 상태([[prototype]])가 있고, 결정의 근거(ADR)와 세션 기록이 쌓입니다. `docs/`가 내놓는 작품이라면 여기는 그것을 만드는 방(atelier)입니다.
애플리케이션 자체에 대한 문서(요구사항, 아키텍처, UX 설계, 상세 설계, 명세)는 `docs/`에 있습니다. → [[docs/README|문서 색인]]

## `docs/`와의 차이

| | `docs/` | `atelier/` |
| --- | --- | --- |
| 대상 | 애플리케이션 | 우리가 하고 있는 일 |
| 내용 | 지금의 모습: 요구사항, 설계, 명세 | 지금 하는 일: 현재 상태, 할 일, 답을 기다리는 것, 프로토타입. 거기에 이른 과정: 결정 기록(ADR), 세션 기록, 검토 |
| 수명 | 제품과 함께 계속 유지 | 세션 기록은 쌓이고, 계획은 진행에 따라 갱신 |

논의 끝에 결정이 나면 **무엇이 되었는지**는 `docs/`(요구사항, 설계)에 반영하고, **왜 그렇게 정했는지**는 ADR(`adr/`)에 남깁니다. 세션 기록과 상태 문서에는 링크만 남깁니다.

이 폴더의 이름은 `collab/`(2026-10-07) → `plan/`(2026-10-09) → `atelier/`(2026-10-12)로 바뀌어 왔습니다. 세션 기록과 타임라인에 적힌 `plan/…` 경로는 그때의 기록이고, 지금의 `atelier/…`입니다.

2026-10-12까지 ADR은 `docs/03-adr/`에 있었습니다. `docs/`에는 최종 모습만 두기로 하면서 이곳으로 옮겼습니다.

## 아키텍처 결정 기록 (ADR)

ADR은 아키텍처 결정의 기록입니다. 이 저장소에서는 아키텍처가 아닌 결정(일하는 순서, 조작과 모습, 이름 · 로고 · 라이선스)도 같은 형식과 같은 번호 줄로 적어 왔습니다. 그래서 목록을 **아키텍처 결정**과 **그 밖의 결정** 둘로 나눕니다(2026-10-17). 파일과 번호는 그대로입니다. ADR 하나는 한 묶음에만 있고, 묶음 안에서는 번호 순서입니다.
