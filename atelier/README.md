# 아틀리에 (일하는 과정의 기록)

메인테이너와 Claude가 의논하고, 결정하고, 계획을 세우는 작업실(atelier)입니다. `docs/`가 내놓는 작품이라면 여기는 그것을 만드는 방입니다.
애플리케이션 자체에 대한 문서(요구사항, 아키텍처, UX 설계, 상세 설계, 명세)는 `docs/`에 있습니다. → [[docs/README|문서 색인]]

## `docs/`와의 차이

| | `docs/` | `atelier/` |
| --- | --- | --- |
| 대상 | 애플리케이션 | 우리가 일하는 과정 |
| 내용 | 지금의 모습: 요구사항, 설계, 명세 | 거기에 이른 과정: 결정 기록(ADR), 논의, 검토 중인 생각, 계획, 할 일 |
| 수명 | 제품과 함께 계속 유지 | 세션 기록은 쌓이고, 계획은 진행에 따라 갱신 |

논의 끝에 결정이 나면 **무엇이 되었는지**는 `docs/`(요구사항, 설계)에 반영하고, **왜 그렇게 정했는지**는 ADR(`adr/`)에 남깁니다. 세션 기록과 상태 문서에는 링크만 남깁니다.

이 폴더의 이름은 `collab/`(2026-10-07) → `plan/`(2026-10-09) → `atelier/`(2026-10-12)로 바뀌어 왔습니다. 세션 기록과 타임라인에 적힌 `plan/…` 경로는 그때의 기록이고, 지금의 `atelier/…`입니다.

2026-10-12까지 ADR은 `docs/03-adr/`에 있었습니다. `docs/`에는 최종 모습만 두기로 하면서 이곳으로 옮겼습니다.

## 구성

질문 하나에 문서 하나입니다. 한 항목은 한 곳에만 적고, 다른 문서에서는 링크로 가리킵니다.
