# 로고와 아이콘 파일 만들기

## 한 줄 요약

로고는 그림 한 장이 아니라 **쓰는 자리마다 다른 파일 묶음**입니다. 큰 그림을 그대로 줄이면 뭉개지므로 작은 크기용을 따로 만들고, 글자는 글꼴이 없어도 보이도록 윤곽선으로 바꿉니다.

## 백엔드로 비유하면

- **비트맵(PNG, JPG)과 벡터(SVG)** = 계산 결과를 저장한 것과 계산식을 저장한 것. 비트맵은 점의 표라서 키우면 깨지고, 벡터는 "이 좌표들을 잇는 면을 이 색으로 칠하라"는 식이라서 어느 크기로든 다시 그립니다. 로고의 원본은 벡터로 둡니다.
- **사진을 벡터로 옮기기(트레이싱)** = 로그에서 집계 테이블 만들기. 사진의 수많은 색을 몇 가지로 묶고(색 군집, 또는 밝기 기준), 같은 묶음끼리 이어진 덩어리의 테두리를 따서 면으로 만듭니다. 묶을 때 가는 선과 잔무늬는 사라집니다. 벽화의 눈이 뭉개진 까닭입니다.
- **크기별 판** = 화면마다 다른 응답(목록 API는 요약만, 상세 API는 전부). 16px에는 점이 256개뿐이라 진주 줄을 그릴 자리가 없습니다. 그래서 작은 판에서는 무엇을 뺄지를 사람이 정합니다. 자동으로 줄이는 것은 "전부 조금씩 흐리게"일 뿐입니다.
- **글자를 윤곽선으로 바꾸기** = 의존성을 묶어 넣은 실행 파일. SVG 안의 글자는 보는 사람의 컴퓨터에 그 글꼴이 있어야 제 모양으로 보입니다. 글자를 도형으로 바꿔 넣으면 글꼴이 없어도 똑같이 보입니다. 대신 글자를 고치려면 다시 만들어야 합니다.
- **`<picture>`와 `prefers-color-scheme`** = 요청 헤더에 따라 다른 파일을 주는 콘텐츠 협상. 보는 사람의 화면이 어두운 테마면 밝은 글자의 그림을, 아니면 어두운 글자의 그림을 고릅니다. GitHub의 README에서도 됩니다.
- **라이선스** = 라이브러리 라이선스와 같은 생각입니다.

| 표시 | 뜻 | 로고에 써도 되나 |
| --- | --- | --- |
| 퍼블릭 도메인, CC0 | 조건 없음 | 됨 |
| CC BY | 출처를 밝혀야 함 | 되지만 로고마다 출처를 적기 어려움 |
| CC BY-SA | 만든 것도 같은 조건으로 공개해야 함 | 피함 |
| CC … NC | 돈 버는 데 쓰면 안 됨 | 후원·광고·유료 버전과 맞지 않음 |
| OFL (글꼴) | 글꼴로 만든 결과물은 자유 | 됨 |

오래된 작품이라도 **그 작품을 찍은 사진**에는 찍은 사람의 권리가 따로 있을 수 있습니다. 조각처럼 입체인 것은 특히 그렇습니다.

## AriadneNSD에서 어디에 쓰나

- **바탕 그림:** 메트로폴리탄 미술관이 CC0로 공개한 벽화 모사화의 사진입니다. → [[logo-source]]
- **그림 로고:** 크노소스 벽화의 가운데 여인을 색 면 네 가지(바탕, 머리, 살, 가는 선)로 옮겼습니다. 눈은 뭉개져서 자리를 재어 다시 그렸습니다. → `journal/assets/2026-10-10-logo-aegean-lady.svg`
- **크기별 판:** 32px부터는 벽화 그대로, 16~24px은 머리·얼굴·눈만 남기고 얼굴을 더 크게 잡은 판입니다. → `…-lady-tiny.svg`
- **문자 로고:** `Ariadne`는 GFS Didot, `NSD`는 IBM Plex Mono이고, 둘 다 윤곽선으로 바꿨습니다. 밝은 화면용과 어두운 화면용 두 파일입니다. → `journal/assets/2026-10-10-wordmark-light.svg`, `…-dark.svg`
- **만든 방법:** Python 스크립트(`journal/assets/2026-10-10-logo-trace-*.py`, `…-logo-wordmark.py`)로 뽑았습니다. 사진을 바꿔 다시 돌릴 수 있지만, 자르는 자리 같은 값은 코드에 적혀 있습니다.
- **아직 없는 것:** Obsidian 리본 아이콘(단색 SVG만 받음), 데스크톱 아이콘 파일(Windows는 여러 크기를 한 파일에 담은 `.ico`), 파비콘 파일.
