AriadneNSD는 NS 차트(Nassi-Shneiderman Diagram) 편집기입니다. 지금은 설계 단계이며, 이 사이트는 저장소의 설계 문서를 웹에서 읽을 수 있게 펴낸 것입니다.

- **[[docs/README|설계 문서]]**: 요구사항, UX 설계, 아키텍처, 상세 설계, 파일 형식 명세. 여기서 시작하세요.
- **[[atelier/README|작업 공간]]**: 결정 기록(ADR · DR), 지금 상태, 할 일, 세션 기록.

원본은 GitHub 저장소 [reddiana/AriadneNSD](https://github.com/reddiana/AriadneNSD)에 있습니다. 메인테이너는 이 문서들을 Obsidian으로 쓰고 읽습니다. 저장소를 받아 Obsidian으로 열면 같은 내용을 더 편하게 볼 수 있습니다.

> [!info] 미완성
> 웹 버전 앱과 사용자 매뉴얼은 아직 없습니다. 생기면 같은 사이트의 `app/`과 `manual/`에 둡니다.
