# 두 사람이 서로 기다리지 않게 일하는 순서

메인테이너가 물었다: "이런 방식으로 일하는 것을 뭐라고 부르나요? 산업공학에서 이런 공정이나 프로세스를 부르는 용어가 있을 것 같네요." 그리고 "두명의 작업자가 서로의 공정에 대한 입력물을 주고 받아면서 일의 순서를 조절해서 전체 시간을 줄이는 그런 방법"(2026-11-02).

## 상황

메인테이너가 결정을 내리면 Claude가 그것을 반영하고, Claude가 시안을 내면 메인테이너가 본다. 서로의 결과가 서로의 입력이다. Claude가 긴 반영 작업을 끝낸 뒤에야 다음 시안을 내면, 그동안 메인테이너는 기다린다.

## 이름들

| 이름 | 무엇 | 이 상황에서 |
| --- | --- | --- |
| 사람-기계 작업 분석 (Man-Machine Chart, 다중 활동 분석) | 사람과 기계가 언제 일하고 언제 노는지(유휴 시간) 나란히 그려, 서로 기다리는 시간을 줄인다 | 메인테이너와 Claude의 시간을 두 줄로 그려 보면 빈 칸이 보인다 |
| 존슨의 규칙 (Johnson's rule) | 모든 일이 A → B 두 공정을 거칠 때, 앞 공정이 짧은 일을 먼저 해서 뒤 공정이 빨리 시작하게 하는 순서 규칙 | 금방 낼 수 있는 시안을 먼저 내고, 긴 반영은 그 뒤에 |
| 잭슨의 규칙 (Jackson's rule) | 존슨의 규칙을 넓힌 것. 어떤 일은 A → B, 어떤 일은 B → A로 흐르는 두 기계 잡숍의 순서 | 결정(메인테이너 → Claude)과 시안(Claude → 메인테이너)이 양쪽으로 흐르는 지금이 이것 |
| 동시 공학 (Concurrent Engineering) | 앞 공정이 끝나기 전에 중간 결과를 넘겨 뒤 공정을 겹쳐 진행한다 | 시안의 첫 판을 빨리 내고, 다듬기는 보는 동안 |
| 바통 터치 (Baton touch, 토요타 생산 방식) | 두 작업자 사이에 넘겨주는 구간을 고정하지 않고, 먼저 끝난 사람이 상대 쪽 일을 받는다 | 메인테이너가 보는 동안 Claude가 기록 · 테스트를 한다 |
| 파이프라이닝 (Pipelining) | 소프트웨어 쪽 말. 단계를 겹쳐 처리량을 올린다 | CPU의 명령 파이프라인과 같은 생각 |

## AriadneNSD에서 정한 것

- 물을 것이 보이면 미리 한꺼번에 먼저 묻는다. 메인테이너는 답하고 다른 일을 하고, Claude는 그동안 일한다.
- 검토할 것(시안, 결정 질문)이 생기면 먼저 내보내고, 메인테이너가 보는 동안 긴 작업을 한다.
